งบเทคชุดวันนี้ออกมาใช้ได้…

📱 META +4%

รายได้เกินทั้งตลาดและ bar ของบายไซด์ และกรอบบนของไกด์ 4Q อยู่เหนือ bogey ที่ ~$75B โดยรวมเป็นตัวเลขที่แน่น แต่นักลงทุนยังเตรียมใจรับการระดมทุนด้วยหุ้น (equity raise) ที่อาจเกิดขึ้น (ดูว่าในการประชุมสายจะได้ข้อมูลเรื่องจังหวะหรือไม่)

3Q ออกมาเหนือกรอบบนของไกด์ ขับเคลื่อนหลักโดยราคา (ราคาต่อโฆษณา +14%, impressions +10%) ไกด์ค่าใช้จ่าย FY26 ขึ้นเป็น $175–179B แต่นั่นเป็นเพียงการบวกค่าใช้จ่ายค้างจ่ายคดีของอัยการสูงสุด (AG) $9.9B เข้าไป หากหักรายการนี้ก็ยังเป็น $165–169B ซึ่งค่อนข้างโล่งใจ Capex ถูกบีบแคบโดยยกเฉพาะขอบล่างขึ้น จุดกึ่งกลางจึงเป็น $140B ซึ่งต่ำกว่า $140–145B ที่บายไซด์คาดเล็กน้อย เป็นความผิดหวังเล็กน้อยสำหรับกระทิงเซมิฯ AI และบวกเล็กน้อยสำหรับ META long

เรื่องปี 2027 ฝ่ายบริหารบอกว่ายังจัดทำงบประมาณและแผนกำลังการผลิตอยู่ และจะ "ลงทุนอย่างก้าวร้าว" ต่อไป อย่าลืมว่า bogey อยู่ราว ~$215–220B ของ opex / ~$250B ของ capex และควรได้รายละเอียดในการประชุมสาย ไกด์ ex-charge ที่ไม่เปลี่ยนสื่อว่าค่าใช้จ่าย 4Q ราว ~$48–52B เพิ่มจาก $41.7B ใน 3Q นั่นเป็น run rate ต่อปีราว ~$200B ก่อนการเติบโตใดๆ ในปี '27 แล้ว ข่าว share-class ของ Semafor ที่ออกใกล้ปิดตลาดเป็นความจริง: หุ้น Class C ไม่มีสิทธิออกเสียง มีผล 19/1/27 สร้างผ่านเงินปันผลเป็นหุ้นอัตรา 1 ต่อ 1 (เทียบเท่าการแตกหุ้น 2 ต่อ 1) โดยมีการระดมทุนเป็นเหตุผลแรกที่ระบุ FCF ติดลบ $2.1B บน capex $34.9B

  • รายได้ 3Q: $64.6B, +26% cc เทียบตลาด $63.3B และ bogey $64B+
  • ราคาต่อโฆษณา / impressions 3Q: +14% / +10% y/y
  • ไกด์รายได้ 4Q: $73–76B (+22–27% y/y โดยมีแรงต้านจาก FX ~1 จุด) เทียบตลาด $73.6B และ bogey ~$75B+ ที่ขอบบน
  • ค่าใช้จ่ายรวม FY26: $175–179B รวมรายการ $9.9B ($165–169B ถ้าไม่รวม, ไม่เปลี่ยน)
  • Capex FY26: $135–145B เทียบเดิม $130–145B, ตลาด ~$142B และ bogey $140–145B
  • FY27: ไม่มีไกด์ค่าใช้จ่ายหรือ capex; "การเติบโตของรายได้โดยรวมแข็งแกร่งตลอดปี 2027"; ขาดทุน Reality Labs ~$15B เทียบ $18–19B ใน FY26
  • EPS 3Q: $3.83 GAAP; $7.40 หากไม่รวมรายการดังกล่าว

🔌 TXN ทรงตัว

รายได้เท่า bogey พอดี แต่ GM และไกด์ 4Q สูงกว่า เป็นตัวเลขแน่นแม้เป็นหุ้นที่ crowded long อยู่แล้วก่อนงบ (ยัง +60% YTD) ซึ่งเป็นเหตุผลที่ราคาหุ้นไม่ขึ้น

รายได้ 3Q $6.06B (+11% q/q, +28% y/y) ชนะตลาดราว ~2% แต่ตกที่ $6.05–6.1B ของบายไซด์พอดี จึงไม่มี upside ด้านบนสุดเทียบตัวเลขบายไซด์

สิ่งที่ดีกว่าอยู่ที่อื่น:

  • GM อยู่ที่ 64.2% เหนือตลาด ~260bps และเหนือ bogey ~62.5% อยู่ ~170bps
  • จุดกึ่งกลางไกด์ 4Q $6.05B ทรงตัว q/q เทียบการลดตามฤดูกาลปกติ ~−6% และสูงกว่า bogey ~$5.95B
  • จุดกึ่งกลางไกด์ EPS 4Q $2.62 เทียบ bogey $2.40

ที่ $6.05B ไตรมาส 4 ตีเป็นรายปีได้ ~$24B ดังนั้น $25.1B ของตลาดสำหรับ C27 ต้องการเพียงครึ่งปีแรกที่ดีกว่าฤดูกาลเล็กน้อยก็ดูอนุรักษ์ FCF $2.96B เมื่อ capex ลดเหลือ $463M จาก $1.2B เมื่อปีก่อน การสร้างโรง 300mm กำลังทยอยจบ และจุดเปลี่ยน FCF ที่กระทิงเล่นอยู่ก็ปรากฏ Analog โต +32% y/y และ Embedded +21%

  • รายได้ 3Q: $6.06B เทียบตลาด $5.93B และ bogey ~$6.05–6.1B
  • GM 3Q: 64.2% เทียบตลาด 61.6% และ bogey ~62.5%
  • EPS 3Q: $2.62 เทียบตลาด $2.43 และ bogey ~$2.50
  • FCF 3Q: $2.96B เทียบตลาด $2.26B
  • ไกด์รายได้ 4Q: $5.80–6.30B (กึ่งกลาง $6.05B, ทรงตัว q/q) เทียบตลาด $5.76B และ bogey ~$5.95B
  • ไกด์ EPS 4Q: $2.45–2.79 (กึ่งกลาง $2.62) เทียบตลาด $2.31 และ bogey ~$2.40

🔧 LRCX −7%

ไตรมาสกันยายนชนะเล็กน้อย แต่ไกด์ธันวาคมแค่เท่าตลาดที่ $8.6B ขณะที่บายไซด์อยู่ที่ ~$9B

รายได้กันยายน $8.22B และ GM 52.4% ตรง bogey และสูงกว่าตลาดเล็กน้อย แต่ไกด์พลาด: $8.60B ±$400M คือ ~+5% q/q ครึ่งหนึ่งของ bogey บายไซด์ +10% อัตรากำไรและ EPS ในไกด์แค่เท่ากับตลาด ได้ยินเสียงโต้แย้งเรื่องคุณภาพของการชนะ เพราะจีนกระโดดเป็น 35% ของรายได้จาก 26% ในเดือนมิถุนายน ทำให้จีนคิดเป็น ~$1.1B ของการเพิ่ม q/q ~$1.5B; ถ้าไม่รวมจีน รายได้โต ~7% q/q

หุ้นลงมาราว ~40% จากจุดสูงสุดเดือนมิถุนายนอยู่แล้ว (semicap แทบทรงตัว YTD ซึ่งเป็นเรื่องปกติ) แต่นี่น่าจะทำให้ semicap ยังเป็น "ชอร์ตเพื่อระดมเงิน" ในกลุ่มเซมิฯ ในการประชุมสายควรมีการวางกรอบ '27 บ้าง: $215B+ คือสิ่งที่กระทิงต้องการ

  • รายได้ F1Q: $8.22B เทียบตลาด $8.14B และ bogey ~$8.2–8.25B
  • GM F1Q: 52.4% เทียบตลาด 51.8% และ bogey ~52.5%
  • EPS F1Q: $2.20 เทียบตลาด $2.18
  • สัดส่วนจีน: 35% เทียบ 26% ในไตรมาสมิถุนายน
  • ไกด์รายได้ F2Q: $8.60B ±$0.4B เทียบตลาด $8.57B และ bogey ~$9.0–9.1B
  • ไกด์ GM F2Q: 52.5% เทียบตลาด 51.9% และ bogey ~52–52.5%
  • ไกด์ EPS F2Q: $2.33 เทียบตลาด $2.33

🖥️ IBM +5%

ซอฟต์แวร์เด้งกลับเป็น +9% cc จาก +4% ใน 2Q เมื่อดีลที่เลื่อนปิดได้แล้ว ไกด์ FCF ปรับขึ้น

รายได้ $17.1B (+6% cc) ชนะตลาดราว ~2% โดยซอฟต์แวร์นำหน้า ~$200M

  • ซอฟต์แวร์: Data (+20% cc), Transaction Processing (+10% cc) และ Red Hat (+11%) ดีกว่า Automation (−3%) เป็นจุดอ่อน
  • โครงสร้างพื้นฐาน (Infrastructure): +5% cc เทียบตลาด +2% แม้ Z −19% cc ในปีนอกวัฏจักร เพราะ Distributed โต +32%
  • Consulting: +2% cc ตรงตามคาด ยังไม่มีการเร่งตัวกลับ

อัตรากำไรก่อนภาษีจากการดำเนินงานเพิ่ม 70bps y/y รายได้ FY26 ย้ำที่ +4–5% cc และไกด์ FCF ตอนนี้เติบโต >$1B y/y ทั้งที่ FCF 3Q $3.0B ต่ำกว่าตลาดเล็กน้อย หลังซอฟต์แวร์พลาดใน 2Q bar ก็แค่ "แสดงว่าดีลปิดแล้ว" และรอบนี้ผ่านเกณฑ์ ซึ่งน่าจะพอสำหรับหุ้นที่ไม่ crowded เตือนความจำ: หุ้น +4% วันนี้

  • รายได้ 3Q: $17.1B, +6% cc เทียบตลาด $16.8B, +3.8% cc
  • ซอฟต์แวร์ 3Q: $7.8B, +9% cc เทียบตลาด $7.6B, +6% cc (2Q +4% cc)
  • Consulting 3Q: $5.3B, +2% cc เทียบตลาด $5.4B, +2% cc
  • Infrastructure 3Q: $3.7B, +5% cc เทียบตลาด $3.6B, +2% cc
  • EPS ดำเนินงาน 3Q: $2.95 เทียบตลาด $2.85
  • FCF 3Q: $3.0B เทียบตลาด $3.2B
  • ไกด์ FY26: รายได้ +4–5% cc (ย้ำ); การเติบโต FCF >$1B y/y (ปรับขึ้น)

⚖️ ข้อสงวนสิทธิ์ (Disclaimer)

จดหมายข่าวนี้เผยแพร่เพื่อวัตถุประสงค์ด้านข้อมูลและการศึกษาเท่านั้น ไม่มีส่วนใดเป็นคำแนะนำการลงทุนเฉพาะบุคคล คำแนะนำที่ปรับให้เหมาะกับสถานการณ์ของใครคนใดคนหนึ่ง คำเสนอ หรือการชักชวนให้ซื้อขายหลักทรัพย์หรือตราสารทางการเงินใด ๆ จดหมายข่าวนี้ไม่ใช่บริการให้คำปรึกษาด้านการลงทุน และไม่ก่อให้เกิดความสัมพันธ์แบบที่ปรึกษาหรือผู้ดูแลผลประโยชน์ระหว่างผมกับผู้อ่านคนใด

ผมซื้อขายหลักทรัพย์ที่กล่าวถึงที่นี่อยู่จริง และมักเป็นการเทรดระยะสั้น สถานะของผมอาจไม่สอดคล้องกับมุมมองที่เขียนไว้ และผมอาจซื้อหรือขายได้ทุกเมื่อ — รวมถึงทันทีก่อนหรือหลังเผยแพร่ — โดยไม่แจ้งหรืออัปเดต ราคาเป้าหมาย สถานการณ์ขาขึ้น/ขาลง และกรอบเวลาเป็นเพียงความเห็นเชิงอธิบาย ไม่ใช่คำมั่นว่าจะถือต่อ

สิ่งพิมพ์นี้สำหรับการใช้งานส่วนตัวของสมาชิกเท่านั้น ห้ามแจกจ่าย เผยแพร่ซ้ำ ส่งต่อ หรืออ้างอิงโดยไม่ได้รับอนุญาตเป็นลายลักษณ์อักษรล่วงหน้า ลิขสิทธิ์ © 2026 TMT Breakout สงวนลิขสิทธิ์

🎯 Key Takeaways

  1. 📱 META +4%: ชนะ แต่ตลาดยังเตรียมรับการระดมทุน — รายได้ $64.6B, ไกด์ 4Q $73–76B; ไกด์ค่าใช้จ่าย FY26 $175–179B คือบวกรายการ AG $9.9B (ไม่รวม = $165–169B); ข่าวหุ้น Class C ไม่มีสิทธิออกเสียง (มีผล 19/1/27) เป็นความจริงโดยระบุการระดมทุนเป็นเหตุผลแรก
  2. 🧮 ตัวเลขที่ต้องจับตาใน META call — ปี 2027 ยังไม่มีไกด์ (bogey opex ~$215–220B / capex ~$250B); 4Q expenses ~$48–52B เท่ากับ run rate ~$200B ต่อปีก่อนการเติบโต '27
  3. 🔌 TXN ทรงตัว: GM 64.2% และไกด์ 4Q $6.05B (ทรงตัว q/q เทียบฤดูกาล ~−6%) — รายได้เท่า bogey; FCF $2.96B เมื่อ capex ลดเหลือ $463M; $25.1B ของ C27 จึงดูอนุรักษ์
  4. 🔧 LRCX −7%: ไกด์ $8.6B เท่าตลาดแต่ครึ่งหนึ่งของ bogey บายไซด์ — จีนเป็น 35% ของรายได้ (~$1.1B จากการเพิ่ม q/q ~$1.5B); ถ้าไม่รวมจีนโต ~7% q/q; semicap น่าจะยังเป็น funding short
  5. 🖥️ IBM +5%: ซอฟต์แวร์ +9% cc เมื่อดีลที่เลื่อนปิดแล้ว — Data +20%, Red Hat +11%, Distributed +32%; ไกด์ FCF ปรับขึ้นเป็นโต >$1B y/y
  6. 🧭 ภาพรวม — ชุดงบวันนี้ "ใช้ได้" แต่ราคาหุ้นสะท้อน crowding เป็นหลัก: ชนะแล้วไม่ขึ้น (TXN) หรือไกด์ไม่ถึง bogey แล้วลง (LRCX)
