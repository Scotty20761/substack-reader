02Summary Thoughts — บทสรุปความคิดเห็นSummary Thoughts

Key points
  • ผลงานแข็งแรง ไกด์สูงกว่าคาดมาก และบริษัทยืนยันดีลใหม่กับ MSFT (UBS มองว่าเป็นแบบคลาวด์)
  • ดีล OCI (แนวโน้มเป็นฮาร์ดแวร์) และการเร่งตัวของ AMZN ทำให้ฐานลูกค้าเริ่มกระจาย แต่ OpenAI ยังสำคัญที่สุดด้วยระยะห่างมาก
  • RPO ส่วน OpenAI ถูกปรับลดสุทธิ เพราะความล่าช้าของ powered shell ที่ทำให้ OpenAI เรียกร้อง "เครดิต" ได้ ไม่ใช่การลดความต้องการ
  • UBS ปรับลดประมาณการและ PT เหลือ $155 แต่คง Buy เพราะมองว่าตลาดให้น้ำหนักกับความกังวลนี้มากเกินไป

ผลงานออกมาแข็งแรง ไกด์ไตรมาสหน้าสูงกว่าที่คาดมาก และบริษัทยืนยัน[ข้อสันนิษฐานของเรา](ลิงก์ในต้นฉบับ)ว่ามีดีลใหม่กับ MSFT (เราคิดว่าเป็นดีลแบบคลาวด์ แม้รายละเอียดที่บริษัทเปิดเผยจะมีน้อย) เมื่อรวมกับดีล OCI ใหม่ (ที่เราคิดว่าเป็นดีลแบบฮาร์ดแวร์) และการเริ่มเร่งตัวของ AMZN ฐานลูกค้าก็เริ่มกระจายตัวมากขึ้น — แต่ OpenAI ยังเห็นได้ชัดว่าเป็นลูกค้าที่สำคัญที่สุด (ด้วยระยะห่างที่มาก) และจะเป็นตัวกำหนดพลังกำไรต่อหุ้น (EPS power) ในช่วงไม่กี่ปีข้างหน้า

เรามองว่าสารที่สื่อออกมาค่อนข้างปนกัน เพราะ CBRS ยังไม่ได้รัน GPT-6 Astra ให้อินสแตนซ์ที่เปิดสู่สาธารณะ และมีการปรับลดสุทธิในส่วนของ OpenAI ใน RPO (remaining performance obligations หรือภาระผูกพันที่ยังไม่รับรู้) ของ CBRS แต่เมื่อเจาะรายละเอียด สาเหตุที่แท้จริงคือความล่าช้าของ powered shell ของดาต้าเซ็นเตอร์ ซึ่งทำให้ OpenAI อาจเรียกร้อง "เครดิต" เทียบกับสัญญาได้ เรากังวลอยู่บ้างเรื่องความยั่งยืนของความสัมพันธ์นี้ เพราะมีการเปลี่ยนแปลงบุคลากรที่ OpenAI แต่ CBRS ยังคงย้ำว่านี่คือสัญญาแบบ take or pay จริง โดยมีความเสี่ยงทางกฎหมายสูงผูกอยู่หากใครถอยออก

สรุปคือ เราชอบที่ฐานลูกค้ากำลังกระจายตัว แต่เราเลือกมองการเร่งตัวของ OpenAI อย่างระมัดระวังขึ้น จึงปรับลดประมาณการและ PT เหลือ $155 ทว่าเรตติ้งยังคง Buy เพราะเราคิดว่าตลาดให้น้ำหนักกับความกังวลนี้มากเกินไป (over-indexed)

03Analysis/Key Highlights — ประเด็นวิเคราะห์สำคัญAnalysis/Key Highlights

Key points
  • รายได้ core ไตรมาส 3 $231MM สูงกว่า UBSe/Street ราว 7-8%; GM 41.0%; EPS $0.12
  • ไกด์ Q4 รายได้ core $310-330MM (+39% Q/Q), GM 47-49% (สูงกว่าที่ UBS คาด ~580bps); ไกด์ FY26 $940-960MM
  • RPO ขึ้น $700M Q/Q เป็น $26.1B; ค่าปรับต่ำกว่า $1B มาก และ OAI ยกเลิกได้เฉพาะส่วนที่ล่าช้าเกิน 90 วัน (<5% ของ 750MW)
  • กำลังการผลิตอ้างถึง ~700MW ภายในสิ้น CY27 โดย ~75% อยู่นอกสหรัฐฯ; CS-5 เข้าผลิตกลางปี 2027 เร็วกว่าเป้า 2H27
  • ผลประกอบการ (Results): CBRS รายงานรายได้ core ไตรมาส 3 ที่ $231MM สูงกว่าประมาณการของ UBS (UBSe) และ Street ราว 7-8% แยกตามส่วนงาน รายได้ Core Hardware ราว $86MM สูงกว่า UBSe/Street ที่ $68MM/$67MM ราว $18-19MM ขณะที่รายได้ Core Cloud & Services $145MM ต่ำกว่าที่คาดราว $2-3MM อัตรากำไรขั้นต้น (GM) 41.0% สูงกว่า UBSe/Street ราว 200bps/180bps และอัตรากำไรจากการดำเนินงาน (OpM) สูงกว่า 9-10% ส่งผลให้ EPS อยู่ที่ $0.12 เทียบกับ UBSe/Street ที่ ($0.20)/($0.15)
  • ไกด์ (Guidance): ฝ่ายบริหารไกด์รายได้ core ไตรมาส 4 โต 39% Q/Q เป็น $310-330MM สูงกว่า UBSe/Street ที่ $278MM/$275MM มาก ส่วน Core Cloud & Services คาดว่าจะทรงตัว Q/Q เพราะกำลังการผลิตดาต้าเซ็นเตอร์ในระยะใกล้ยังเป็นข้อจำกัด ไกด์อัตรากำไรขั้นต้น 47-49% สูงกว่าที่เราคาดราว 580bps และไกด์ OpM ที่ -1% ถึง 1% ก็แข็งแรงกว่าที่คาด ด้วยเหตุนี้ ฝ่ายบริหารจึงคาดรายได้ core ปี FY26 ที่ $940-960MM, GM 42-44% และ OpM -10% ถึง -8%
  • อัตรากำไรขั้นต้น (Gross Margin): GM ไตรมาส 3 แยกตามส่วนงานคือ 31.0% ในฮาร์ดแวร์ (-780bps Q/Q) — จากการส่งมอบรอบสุดท้ายภายใต้สัญญาเก่าที่ราคาต่ำกว่า — และ 46.9% ในส่วน Cloud and Services (+510bps Q/Q) จากราคาที่แข็งแรงขึ้นของธุรกิจใหม่ แต่ถูกหักล้างบางส่วนจากลูกค้ารายหนึ่งที่เช่ากำลังการผลิตดาต้าเซ็นเตอร์กลับ (renting back) ในต้นทุนที่สูงกว่า ฝ่ายบริหารคาดว่า GM ฮาร์ดแวร์จะเพิ่มขึ้นในไตรมาส 4 เพราะราคาจากคำสั่งซื้อฮาร์ดแวร์ปัจจุบันแข็งแรงขึ้น
  • กำลังการผลิต (Capacity): หลังการประกาศเพิ่มล่าสุด (ลิงก์ในต้นฉบับ) ตอนนี้ CBRS อ้างถึงกำลังการผลิตราว ~700MW ที่ประกาศไว้ภายในสิ้น CY27 ต่อมาบริษัทประกาศความร่วมมือกับ MSFT — ทำให้ข้อตกลงกับไฮเปอร์สเกลเลอร์รวมเป็น 3 รายในรอบหกเดือนที่ผ่านมา อย่างไรก็ตาม ฝ่ายบริหารระบุว่าราว ~75% ของกำลังการผลิตที่จะเข้าระบบใน CY27 จะอยู่นอกสหรัฐฯ รวมถึงแคนาดา ฝรั่งเศส และนอร์เวย์ สอดคล้องกับเรื่องนี้ บริษัทเซ็นสัญญากำลังการผลิตเพิ่มในนอร์เวย์และฟินแลนด์ภายในไตรมาส 3 และอยู่ในขั้นตอนสุดท้ายของการทำสัญญาดาต้าเซ็นเตอร์ในเซาเปาโล
  • RPO: RPO เพิ่มขึ้น $700M Q/Q เป็น $26.1B มีดีลฮาร์ดแวร์ใหม่เพิ่มเข้ามา โดยไม่รวม Oracle ซึ่งเซ็นหลังวันที่ 30 ก.ย. RPO ยังรวมต้นทุนส่งผ่านของ OAI (pass-through costs: วิศวกรรมแบบไม่เกิดซ้ำและการเตรียมไซต์) ซึ่งเพิ่มเข้ามาทุกครั้งที่ OAI อนุมัติดาต้าเซ็นเตอร์ใหม่ รายการหักเพียงอย่างเดียวคือเครดิตความล่าช้าของ OAI ที่ประมาณการไว้ เรามองว่านี่เป็นการบันทึกที่ระมัดระวัง เพราะ CBRS ไม่ได้บวกกลับข้อเรียกร้องค่าปรับของตนเองต่อผู้รับเหมาก่อสร้างดาต้าเซ็นเตอร์ และรายการหักบางส่วนอาจกลับคืนมาหาก CBRS ไม่ต้องรับผิดชอบต่อความล่าช้า เราเข้าใจว่าค่าปรับต่ำกว่า $1B มาก และ OAI ยกเลิกได้เฉพาะส่วนของกำลังการผลิตที่ล่าช้าเกิน 90 วันเท่านั้น ซึ่งครอบคลุมน้อยกว่า 5% ของ 750MW ถึงสิ้นปี เนื่องจากสัญญาเป็นแบบ take-or-pay และการผิดสัญญาจะทำให้ OAI เผชิญความเสี่ยงทางกฎหมายสูง เรามองการที่สัญญาถูกยกเลิกเป็นเพียงกรณีเลวร้ายที่สุด
  • อัปเดต OAI (OAI Update): ความล่าช้าของดาต้าเซ็นเตอร์ทั่วทั้งอุตสาหกรรมทำให้การเร่งตัวของ OAI ช้ากว่ากำหนด OAI และไฮเปอร์สเกลเลอร์บางรายล้วนล่าช้า และตอนนี้ฝ่ายบริหารคาดว่าจะกลับมาตามกำหนดได้ภายใน 2H27 เทียบกับความคาดหมายก่อนหน้าที่ Tranche 1 จะเร่งเต็มที่เสร็จใน 1H27 บริษัทยังปฏิเสธรายงานที่ว่า CBRS ไม่สามารถรองรับ Astra ในทางเทคนิค และตอนนี้เราเข้าใจว่า Astra ยังไม่ได้รันแบบสาธารณะเพราะกำลังการผลิตไม่พอสำหรับขนาดที่ OAI ต้องการ และจำเป็นต้องกำหนดเพดานการใช้งานแม้หลังเปิดตัวแล้ว เรามองความล่าช้านี้เป็นปัญหาเรื่องจังหวะเวลา ไม่ใช่ปัญหาด้านอุปสงค์หรือเทคโนโลยี และออปชันของ OAI สำหรับกำลังการผลิตเพิ่มอีก 1.25GW ที่เริ่มได้เร็วสุดในปี 2029 ยังเป็นอัปไซด์ระยะยาวที่เป็นไปได้
  • อัปเดต AWS (AWS Update): CBRS คาดว่าจะส่งมอบฮาร์ดแวร์ชุดแรกให้ AWS ในไตรมาส 4 แม้การติดตั้งจะขึ้นกับดาต้าเซ็นเตอร์ของ AWS เองซึ่งล่าช้ากว่ากำหนด ดีลนี้เป็นการเช่าแบบติดตั้งในสถานที่ (on-prem lease) รายได้จึงรับรู้ตามระยะเวลาและอาจไม่สม่ำเสมอ; หาก AWS ซื้อขาดมูลค่าเต็มของสัญญาเช่า รายได้จะถูกรับรู้ทั้งหมดล่วงหน้า ระบบเหล่านี้จะรันโมเดลโอเพนซอร์สบน Bedrock และเรามอง AWS ควบคู่กับ Oracle ว่าเป็นการกระจายความเสี่ยงจากการพึ่งพา OAI ของบริษัท
  • อัปเดตโร้ดแมป (Roadmap Update): CS-4 ใกล้เข้าสู่การผลิตเต็มรูปแบบ โดยให้ประสิทธิภาพและ throughput เป็นสองเท่า และคาดว่าจุดตัดข้ามจาก CS-3 ไป CS-4 จะเกิดใน 1Q27 WSE-5 ใช้เวลาไม่ถึงห้าเดือนจาก tape-out ไปสู่การทดสอบระบบ และคาดว่า CS-5 จะเร็วกว่า CS-4 มากกว่าสองเท่าและเข้าสู่การผลิตกลางปี 2027 ซึ่งเร็วกว่าเป้าหมายเดิมที่ 2H27 การทำ inference แบบแยกส่วน (disaggregated inference) ตอนนี้เปิดใช้งานจริงในการผลิตแล้ว โดยใช้ GPU ของ AMD สำหรับ prefill และ CS-3 สำหรับ decode
