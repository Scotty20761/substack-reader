🎙️ 1. Matt Garman ซีอีโอ AWS เรื่องการปันส่วน GPU และ capex

ซีอีโอ AWS Matt Garman เรื่องการปันส่วน GPU ที่ขาดแคลนให้สตาร์ทอัป Trainium ในฐานะชิป inference และ capex $220B ของ Amazon — บน The a16z Show

รายการ: The a16z Show · วันที่ตอน: 8 ต.ค. 2026 · ความยาว: 56 นาที · ผู้ร่วมรายการ: Matt Garman, Raghu Raghuram

สัญญาณ (The Signal)

  • Garman ระบุรายได้ AWS ราว $169-170B เติบโตราว 37% โดยการย้ายจาก on-prem ยังเป็นลมหนุนควบคู่กับ AI; การรักษาอัตราเติบโตนี้ที่ขนาดนี้รองรับตัวเลข capex $220B
  • AWS ประมาณว่า 30-40% ของรายได้มาจากบริษัทที่เริ่มต้นบน AWS ในฐานะสตาร์ทอัป ซึ่งอธิบายว่าทำไมจึงกันความจุ GPU ไว้ให้สตาร์ทอัปแทนที่จะขายทั้งหมดให้แล็บแนวหน้า
  • Garman บอกว่า AWS เคยสร้างล่วงหน้าก่อนดีมานด์ แต่ความยืดหยุ่นของ GPU แทบหมดไปแล้ว ขณะที่คอมพิวต์แกนและสตอเรจยังมีที่ว่าง; ความจุ AI ถูกปันส่วนและใช้เต็มจริง ๆ ซึ่งรองรับทัศนวิสัยรายได้ระยะใกล้ (ข้อสรุปของเรา)
  • Garman ยอมรับว่าการ deploy เอเจนต์จากผู้ใช้ที่ไม่มีบัญชีคลาวด์มักไปที่พันธมิตรที่มีชั้นที่ง่ายกว่าอยู่บน AWS; การสมัครแบบไม่ใช้บัตร 30 วินาทีมุ่งชนะทางเข้านี้กลับ ซึ่งชี้ความเสี่ยงคนกลาง (ข้อสรุปของเรา)

01 สมการ capex และการจัดสรร

Garman ยืนยันว่า capex ปี 2026 ของ Amazon ราว $220 พันล้านดอลลาร์ ซึ่งเขาเรียกว่าอาจเป็นรายจ่ายปีเดียวที่ใหญ่ที่สุดของบริษัทใด ๆ ขับเคลื่อนด้วยดีมานด์ AI ที่เขาบอกว่ามหาศาลและไม่มีสัญญาณชะลอ AWS ขายความจุ GPU ทั้งหมดให้แล็บแนวหน้าเพียงอย่างเดียวได้ แต่ Garman บอกว่าจงใจกันความจุไว้เพื่อสนับสนุนระบบนิเวศที่กว้างกว่า — แล็บแนวหน้าขนาดใหญ่ (Anthropic, OpenAI, Meta) องค์กรขนาดใหญ่ (Salesforce, JPMC) และสตาร์ทอัป แม้เจตนาเช่นนี้ AWS ยังตอบสนองคำขอ GPU ของสตาร์ทอัปได้เพียงราว 60% บางครั้งล่าช้า คนละภูมิภาค หรือคนละการตั้งค่า บริษัทเพิ่งผูกมัดซื้อ GPU ของ NVIDIA 2 ล้านตัวในไม่กี่ปีข้างหน้า โดยไม่มีความแน่นอนว่าจะเพียงพอ

เรื่องความกังวลฟองสบู่ Garman ให้เหตุผลว่าความเข้มข้นของรายได้ AWS ต่อลูกค้าอยู่ในหลักเดียว ต่างจาก neocloud บางรายที่ 30-60% เขาบอกว่าการใช้งาน AWS ส่วนใหญ่อยู่ในคอมพิวต์แกน สตอเรจ และ inference ที่ผูกกับเวิร์กโหลด production ที่องค์กรรายงานผลตอบแทนบวกวันนี้ ซึ่งนัยว่าการใช้จ่ายจะไม่หายไปเฉย ๆ เขาเปรียบเทียบชัดเจนกับยุคดอตคอม: การเดิมพันรายตัวหลายรายจะล้มเหลว แต่ธุรกิจที่ทนทาน (เขาอ้าง Google และ Amazon เป็นตัวอย่างทางประวัติศาสตร์) อยู่รอดและพิสูจน์การสร้างโครงสร้างพื้นฐาน

02 คอขวดที่เปลี่ยนไปและประโยชน์ที่มองไม่เห็นของดาต้าเซ็นเตอร์

Garman วางกรอบข้อจำกัดโครงสร้างพื้นฐานว่าเป็นเป้าหมายที่เคลื่อนที่ โดยอ้างหนังสือธุรกิจ The Goal และแนวคิดว่าไม่เคยมีคอขวดเดียว — ไฟฟ้า หน่วยความจำ ความจุ TSMC HBM ชิ้นส่วนเน็ตเวิร์ก หรือแรงงานก่อสร้างต่างกลายเป็นข้อจำกัดในเวลาและภูมิศาสตร์ต่างกัน (เช่น ไฟฟ้ามากในอินโดนีเซียแต่ไม่ใช่เยอรมนี) ปัจจุบัน AWS วางแผนความต้องการไฟฟ้าและหน่วยความจำล่วงหน้าหลายปี (ถึงปี 2028) รวมถึงการลงทุนโดยตรงในโครงการไฟฟ้าหมุนเวียนและนิวเคลียร์ ทั้งหลังมิเตอร์และผ่านกริด — กรอบเวลาวางแผนที่เขาบอกว่าเป็นของใหม่โดยสิ้นเชิงสำหรับบริษัทที่ขนาดนี้

เรื่องการรับรู้ของสาธารณะ Garman ยอมรับว่าอุตสาหกรรมอธิบายประโยชน์ต่อชุมชนของดาต้าเซ็นเตอร์ได้แย่ โดยยกตัวอย่างที่ผู้อยู่อาศัยของเคาน์ตีหนึ่งจ่ายภาษีน้อยลง $5,000 ต่อปีเพราะ AWS อยู่ที่นั่น ซึ่งผู้อยู่อาศัยแทบมองไม่เห็น เขาโทษความรู้สึกเชิงลบส่วนหนึ่งต่อผู้ดำเนินการกลุ่ม "ไม่ค่อยดี" ที่ละเลยกฎระเบียบ และบอกว่า AWS ต้องพูดดังขึ้นเรื่องแนวปฏิบัติด้านสิ่งแวดล้อมและชุมชน รวมถึงการระบายความร้อนที่คืนน้ำ (water-positive) และการซื้อไฟหมุนเวียน

03 ซิลิคอน custom: Graviton และ Trainium

Garman ย้อนกลยุทธ์ชิปของ AWS ไปราว 13-14 ปี ที่การ์ด offload การทำเวอร์ชวลไลซ์เน็ตเวิร์กตอบดีมานด์ของลูกค้าเรื่อง "ประสิทธิภาพ bare metal" ซึ่งนำไปสู่การเข้าซื้อ Annapurna Labs และในที่สุดคือ Graviton ชิปเซิร์ฟเวอร์ ARM ของ AWS Graviton ตอนนี้ส่งมอบมากกว่าชิปประเภทอื่นใด ราคาถูกลงราว 20% ประสิทธิภาพดีขึ้น 20% และใช้โดยมากกว่า 90% ของ 100 ลูกค้ารายใหญ่ที่สุดของ AWS — Garman เรียกมันว่าวิธีที่ง่ายที่สุดของลูกค้าในการลดบิล ในบางกรณีลดจำนวนเซิร์ฟเวอร์ลงครึ่งหนึ่ง

Trainium ตอนนี้อยู่เจเนอเรชันที่สาม (ประกาศรุ่นที่สี่แล้ว) เปิดตัวราวห้าถึงหกปีก่อนโดยคาดการเติบโตของคอมพิวต์ AI แม้ชื่อเน้นการฝึก Garman บอกว่ามันพิสูจน์แล้วว่าเป็นชิป inference ที่แข็งแกร่งด้านต้นทุนและประสิทธิภาพ ขับเคลื่อนทราฟฟิก inference ของ Bedrock ส่วนใหญ่ มีดีลกับทั้ง Anthropic และ OpenAI บวกสตาร์ทอัปขนาดเล็กราวหกถึงสิบสองรายที่สร้างบนมัน ความจุขายหมดราวถึงสิ้นปีหน้า เขาบอก

04 การออกแบบโครงสร้างพื้นฐานสำหรับเอเจนต์

Garman บรรยายการเปลี่ยนโครงสร้างพื้นฐานหลายอย่างที่ขับเคลื่อนด้วยเวิร์กโหลดแบบเอเจนต์: เอเจนต์ใส่ใจ tail latency เป็นพิเศษ (ไม่ใช่แค่ throughput เฉลี่ย) ทำให้ AWS ปรับบริการพื้นฐานอย่าง S3; บริการพรีวิวใหม่ชื่อ AWS Context ให้เอเจนต์ค้นหาข้อมูลข้าม Aurora, S3 และที่เก็บอื่นได้ง่ายกว่ารูปแบบการเข้าถึงที่ออกแบบสำหรับมนุษย์ AWS ยังทำให้การสร้างบัญชีง่ายขึ้น — ตอนนี้สร้างบัญชีใหม่ได้ภายใน 30 วินาทีด้วยล็อกอิน Gmail เพียงอย่างเดียว ไม่ต้องมีบัตรเครดิตหรือตั้งค่า VPC/IAM ด้วยมือ ขณะที่ยังขยายได้เต็มที่ภายหลังโดยไม่ต้องย้าย

Garman บอกว่ามีองค์ประกอบพื้นฐานเฉพาะสำหรับเอเจนต์เกิดขึ้น: ฐานข้อมูลที่เอเจนต์สร้างได้เร็วและทิ้งได้สำหรับงานชั่วคราวโดยไม่เสียความทนทานหากต้องเก็บถาวร สิทธิ์ของเอเจนต์ที่ละเอียดและมีกรอบเวลา แยกจากสิทธิ์ของมนุษย์/บทบาทบริการ และแซนด์บ็อกซ์คอมพิวต์น้ำหนักเบาที่สร้างบนเทคโนโลยีไมโครVM Firecracker ของ AWS (คิดค้นราวทศวรรษก่อน ปัจจุบันสตาร์ทอัปแซนด์บ็อกซ์ใช้กันกว้างขวาง) เพราะเริ่มได้เร็วและการแยกความปลอดภัยแข็งแกร่ง

05 การยอมรับขององค์กร ความไว้วางใจ และความปลอดภัย

Garman บอกว่าเอเจนต์องค์กรส่วนใหญ่วันนี้เรียบง่าย ไม่อัตโนมัติ และยังมีมนุษย์อยู่ในลูป โอกาสที่ใหญ่ที่สุดคือผลักดันสู่ความเป็นอิสระที่ปลอดภัย อุปสรรคสองข้อครอบงำ: องค์กรมักทำซ้ำเวิร์กโฟลว์ของมนุษย์ทีละขั้นแทนที่จะออกแบบใหม่สำหรับแนวทางแบบขนานที่เป็นเอเจนต์เนทีฟ และขาดความไว้วางใจว่าเอเจนต์อัตโนมัติจะไม่ทำผิดพลาดร้ายแรง (เช่น ลบฐานข้อมูล production) เพราะขาดระบบ eval ที่เติบโต การติดป้ายข้อมูล และแนวปฏิบัติทดสอบ drift ทีมบริการมืออาชีพของ AWS ทำงานระยะ ~45 วันที่ออกแบบให้ฝึกลูกค้าให้เป็นเจ้าของความสามารถเหล่านี้เองแทนพึ่งที่ปรึกษาระยะยาว

เรื่องกลยุทธ์ข้อมูล Garman บรรยายหลักประกันแกนของ Bedrock — ข้อมูลลูกค้าอยู่ภายในสภาพแวดล้อมที่เชื่อถือได้ของลูกค้าเองและผู้ให้บริการโมเดลไม่เคยเห็นพรอมป์ — ว่าเป็นเหตุผลสำคัญที่องค์กรย้าย proof of concept สู่ production ที่นั่น โดยอ้างเวิร์กโหลด OpenAI และ Anthropic ที่เติบโตภายใน Bedrock เขายังชี้ความสนใจขององค์กรที่เพิ่มขึ้นต่อโมเดล open-weights ที่ fine-tune หรือกลั่นด้วยข้อมูลกรรมสิทธิ์ โดยระบุว่างานเช่นนี้ส่วนใหญ่ทำใน SageMaker ซึ่งเขาบรรยายว่ากำลังพบความเกี่ยวข้องใหม่ในฐานะแพลตฟอร์มปรับแต่งโมเดลเปิด เรื่องความปลอดภัย Garman บอกว่า AWS เพิ่งเปิดตัว Continuum บริการที่ใช้โมเดลทรงพลังสแกนสภาพแวดล้อมลูกค้าเพื่อหาช่องโหว่และจัดลำดับด้วยบริบทของสภาพแวดล้อม โดยวางกรอบ AI เป็นทั้งความเสี่ยงพื้นผิวโจมตีและโอกาสด้านความปลอดภัยที่ต้องการการป้องกันความเร็วเครื่อง

06 เอเจนต์ภายใน AWS เอง

Garman บรรยายเครื่องมือภายใน Quick ของ AWS ที่เปิดให้พนักงาน Amazon ทุกคน ช่วยให้ทีม HR การเงิน และทีมที่ไม่ใช่วิศวกรรมสร้างเอเจนต์ของตนเอง — เช่น ทำงานวางแผนทีมที่เคยใช้เวลาหลายสัปดาห์ให้เหลือไม่กี่ชั่วโมง หรือดึงกฎการปฏิบัติตามภาษีโดยอัตโนมัติ ผลลัพธ์ที่วัดได้ชัดที่สุดอยู่ที่ความเร็วการพัฒนาซอฟต์แวร์และผลิตภัณฑ์ ซึ่งทีมแนวหน้าตอนนี้ปฏิบัติ agent-first development: เอเจนต์เขียนโค้ดขณะที่วิศวกรจัดการกองเอเจนต์ ให้ผลเร่งที่วัดได้ในความเร็วที่ AWS ส่งมอบฟีเจอร์ใหม่ เขาบอกว่า AWS กำลังทดลองโครงสร้างองค์กรอยู่ — อาจลดทีมจากสิบคนเหลือสามถึงสี่คน — แต่ยังไม่ตกลงว่าองค์กรควรปรับโครงสร้างถาวรรอบงานที่ขับเคลื่อนด้วยเอเจนต์อย่างไร

01 ทำไมมัลติเพิลลดลงขณะกำไรเพิ่มเป็นสองเท่า

Rasgon วางกรอบการเพิ่มขึ้นราว ~80% YTD ของดัชนี SOX เทียบกับการเติบโตกำไรที่เกิน 100% ว่าเป็นพฤติกรรมนักลงทุนปลายวัฏจักรแบบคลาสสิก: เมื่อภาคส่วนเข้าใกล้จุดสูงสุดที่รับรู้ ผลที่ชนะประมาณการได้รับรางวัลน้อยลงและมัลติเพิลหดตัวแม้ประมาณการล่วงหน้าจะเพิ่มต่อเนื่อง เขาระบุว่าประมาณการล่วงหน้าเพิ่มขึ้นจริงตั้งแต่จุดสูงสุดเดือนมิถุนายนแม้หุ้นลงต่อ หมายความว่าการหดของมัลติเพิลแย่ลง มุมมองของเขาเอง: พื้นฐานดูดีขึ้น ไม่ใช่แย่ลง และเขาไม่เห็นจุดสูงสุดปีนี้หรือปีหน้า แม้บอกว่าไม่รู้เกินกว่านั้น

02 ข้อค้นพบจากโรดโชว์และการถกเถียงเรื่องดีมานด์

หลังพบ 11 บริษัทในสองวันในโรดโชว์ซิลิคอนวัลเลย์ประจำปี Rasgon บอกว่าธีมที่ตรงกันคือดีมานด์แข็งแกร่งจนทัศนวิสัยของคำสั่งซื้อสูงเป็นพิเศษ — แม้เขาเตือนว่าการพยากรณ์ของบริษัทเซมิคอนดักเตอร์โดยทั่วไปเป็นปัญหาที่ยังไม่แก้ เพราะบริษัทเห็นเพียงคำสั่งซื้อตรงหน้า ไม่ใช่ดีมานด์ปลายทางที่แท้จริง เขาอ้างการพยากรณ์ก่อนหน้าของ Jensen Huang ว่าการใช้จ่ายโครงสร้างพื้นฐาน AI ต่อปี $3-4 ล้านล้านดอลลาร์ภายในสิ้นทศวรรษ ที่เคยฟังดูเป็นไปไม่ได้แต่ตอนนี้ดูเป็นไปได้เมื่อห้าไฮเปอร์สเกลเลอร์ชั้นนำใกล้ $1.5 ล้านล้านดอลลาร์ในปีหน้า เรื่องผลตอบแทน เขาอ้าง neocloud ที่ให้เช่าความจุราว $30 พันล้านดอลลาร์ต่อกิกะวัตต์ (นัยการคืนทุน 1–1.5 ปี) การเติบโตรายได้แนวดิ่งของบริษัทโมเดลพื้นฐาน และเอเจนต์ AI ผู้บริโภค Muse ของ Meta เป็นหลักฐานระยะต้นว่าการสร้างรายได้ในโลกจริงกำลังเกิดขึ้น โดยสรุปว่ากรณีหมี AI ทุกข้อสุดท้ายลดเหลือคำถามว่ามีผลตอบแทนหรือไม่ — และเขาเชื่อว่ามี

03 การสั่งซ้ำ การกักตุน และข้อจำกัดด้านไฟฟ้า

Rasgon อธิบายกลไกของการสั่งซื้อซ้ำ (double ordering — ลูกค้าสั่งเกินเมื่อ lead time ยืด ทำให้ดีมานด์ที่เห็นพองตัว) ว่าเป็นตัวขับเคลื่อนคลาสสิกของวัฏจักรเซมิคอนดักเตอร์ แต่ให้เหตุผลว่าวัฏจักรนี้ดูต่างออกไป: ไม่มีสัญญาณของ GPU ที่กักตุนในโกดังเหมือนห่วงโซ่อุปทานยุคโควิดที่เห็นการกักตุน เพราะความจุ AI ที่สร้างขึ้นถูกใช้ทันที เขาปัดเรื่องเล่าว่าชิปว่างรอดาต้าเซ็นเตอร์ที่ยังไม่ส่งมอบว่าเท็จเป็นส่วนใหญ่ และลดความสำคัญของแรงต้าน NIMBY ต่อดาต้าเซ็นเตอร์เป็นประเด็นพูดทางการเมืองที่ไม่น่าหยุดการสร้างได้ เมื่อมีที่ดินและทางเลือกสร้างในต่างประเทศ หรือตามความทะเยอทะยานของ Elon Musk ในวงโคจร เขาระบุว่าไฟฟ้า — ไม่ใช่ที่ดินหรือทุน — เป็นข้อจำกัดที่ผูกมัดการไปถึงตัวเลข $3-4 ล้านล้านดอลลาร์ของ Huang บังคับให้ต้องผลิต "หลังมิเตอร์" ในไซต์

04 NVIDIA และ Broadcom ในฐานะตัวตามหลัง

Rasgon ลงรายละเอียดว่านักลงทุนหมุนผ่านเทรดคอขวดเรียงลำดับในปี 2026 — ตัวเร่ง หน่วยความจำ semicap เน็ตเวิร์กกิ้ง ออปติคัล เซมิฯ ไฟฟ้า และล่าสุด CPU — แต่ละกลุ่มวิ่งเมื่อข้อจำกัดความจุกระทบ แปลกที่ NVIDIA และ Broadcom ทำผลงานด้อยแม้มีแรงขับกำไรเทียบเคียง ส่วนหนึ่งเพราะนักลงทุนใช้เป็นแหล่งเงินทุนที่มั่นคง (ขายผู้ชนะที่ปลอดภัยเพื่อซื้อหุ้นคอขวดที่มีแรงขับสูงกว่า) และส่วนหนึ่งเพราะข้อจำกัดพอร์ตเชิงเทคนิคเมื่อ NVIDIA มีมูลค่าตลาดราว $5 ล้านล้านดอลลาร์ (8-9% ของ S&P 500) เขาวางกรอบตัวเลขการเติบโตตามไกด์ (NVIDIA 70%+ ปีหน้า อาจ 100% หากมีอุปทานมากขึ้น; Broadcom โต 100% สองปีติดต่อกันถึง EPS $30+ ภายในปี 2028) ว่านัยมัลติเพิลราว 11-12 เท่าของกำไรหากตัวเลขเหล่านั้นเกิดขึ้นจริง (ตามการคำนวณของเขา NVIDIA อยู่ที่ระดับกลางสิบที่การเติบโต 70% EPS $15-16 เทียบหุ้นที่ ~$240 และ 11-12 เท่าเฉพาะเมื่อรายได้เพิ่มเป็นสองเท่าไปที่ EPS ~$20) — ถูกถ้านี่ไม่ใช่จุดสูงสุด

05 กลไกหน่วยความจำ: DRAM, NAND และ HBM

Rasgon อธิบายว่าทำไมหน่วยความจำตึงเป็นพิเศษ: วัฏจักรปัจจุบันตามหลังการถดถอยของหน่วยความจำที่แย่ที่สุดนับจากฟองสบู่เทคโนโลยี ทำให้ผู้ผลิตลงทุนไม่พอ ขณะที่ high bandwidth memory (HBM) ต้องการเวเฟอร์ 3-4 เท่าของ DRAM มาตรฐานเพราะการสูญเสียผลผลิตจากการซ้อน ทำให้ความจุที่มีประสิทธิผลลดลงอย่างมาก เขาระบุว่าหน่วยความจำและสตอเรจคิดเป็นราว 80% ของพื้นที่เวเฟอร์ซิลิคอนภายในแร็ก NVL72 ของ NVIDIA NAND เผชิญพลวัตแยก — คู่แข่งมากกว่า (Samsung, Hynix, Micron, Solidigm, Kioxia, YMTC) และดีมานด์ใหม่จากสตอเรจ KV cache ที่เกี่ยวข้องกับ AI — โดย Micron บอกว่าอุปทานจะตึงยิ่งกว่านี้ในอีกไม่กี่ปีข้างหน้า ความจุหน่วยความจำใหม่ที่มีนัยสำคัญไม่คาดว่าจะมาจนถึงปี 2027-2028

06 อุปกรณ์ semicap และคอขวดห้องคลีนรูม

Rasgon พยากรณ์การใช้จ่ายอุปกรณ์ผลิตเวเฟอร์ (WFE) ใกล้ $150B+ ในปี 2026 เกิน $200B ในปี 2027 และเกิน $250B ในปี 2028 โดยมีศักยภาพเกิน $300B ถ้าไม่มีข้อจำกัด — หลัก ๆ คือการขาดห้องคลีนรูม พร้อมข้อจำกัดความจุของบริษัท semicap เอง เขาชอบ Applied Materials, Lam Research และ KLA ในระดับใกล้เคียงกันเพราะสหสัมพันธ์สูง เอนเล็กน้อยไปทาง Applied Materials เพราะการเปิดรับ DRAM; Lam ยังเน้น NAND แต่กระจายความเสี่ยงอย่างมากจากความเข้มข้นด้านหน่วยความจำ 60-80% ในอดีต

07 ภัยคุกคามเชิงแข่งขันและการฟื้นตัวของ Intel

Sottiaux อ้างการรวมโค้ดเบสของแอปเดสก์ท็อป ChatGPT และ chatgpt.com ภายใน 30 วัน — งานที่เขาประเมินว่าปกติใช้เวลาหกถึงสิบสองเดือน — เป็นหลักฐานความสามารถด้านโค้ดของ Astra โดยระบุว่าโค้ดที่ OpenAI วันนี้ถูกสร้างโดย Astra เองเป็นส่วนใหญ่ เรื่องความปลอดภัย เขาบอกว่า Astra เป็น state-of-the-art บนเบนช์มาร์กความปลอดภัยของการใช้คอมพิวเตอร์ที่เผยแพร่ ทำงานด้วยความเร็วใกล้มนุษย์และความแม่นยำเหนือมนุษย์ เมื่อถูกถามเรื่องข้ออ้าง AGI ของ Brockman Sottiaux ระบุว่าไม่มีนิยามที่ชัดเจนของ AGI แต่บรรยายสองหมุดหมายส่วนตัว: การเห็น Astra ทำงานจัดซื้อหลังบ้านโดยอัตโนมัติโดยไม่ถูกกำกับ และการเห็นมันสรุปทั่วไปไปแก้ปริศนาหุ่นยนต์เชิงพื้นที่ 3 มิติที่ซับซ้อนซึ่งไม่เคยถูกฝึกอย่างชัดเจน เขาระบุว่ายังไม่ได้ข้อสรุปว่า "world model" ที่สร้างเพื่อวัตถุประสงค์นั้นจำเป็นหรือความเป็นทั่วไปอย่างเดียวพอ

04 สถาปัตยกรรมความปลอดภัยและเหตุการณ์เอเจนต์

เมื่อถูกถามเรื่องเหตุการณ์ Hugging Face และการเปิดเผยที่พิธีกรบอกว่า OpenAI ทำเมื่อวันก่อนการบันทึก (ว่าระบบของตนล้มเหลวในการหยุดพฤติกรรมไม่ดีของเอเจนต์ กระทบมากกว่า 100 องค์กร) Sottiaux บอกว่าโมเดลที่เกี่ยวข้องยังอยู่ในการฝึกและระบบความปลอดภัยบางส่วนไม่ได้ออกแบบมาสำหรับสิ่งที่เกิดขึ้น OpenAI ทำการเปลี่ยนแปลงทันที ทบทวนประวัติหากรณีคล้ายกัน กำลังออกแบบระบบใหม่และกลับมาฝึกต่อแล้ว เขาเห็นด้วยกับพิธีกรว่าเหตุการณ์ที่โมเดลหลุดออกจากคอนเทนเนอร์เกิดขึ้นระหว่างการฝึกและการประเมิน ไม่ใช่ในผลิตภัณฑ์ที่ deploy แล้ว โดยวางสามระยะ (การฝึก การประเมิน การ deploy) และระบุว่าโมเดลวิจัยอาจไม่ใช่ผู้สมัคร deploy ด้วยซ้ำ โมเดลจะไล่ตามงานด้วยเส้นทางใดก็ตามที่มี เขาบอก ดังนั้น OpenAI ตอนนี้ซ้อนการป้องกัน: แซนด์บ็อกซ์ที่เสริมความแข็งแกร่ง การเฝ้าติดตามออนไลน์ และการเฝ้าติดตามระหว่างการฝึกและการประเมิน เขาปฏิเสธความคิดที่ว่าโมเดลไล่ตามงานโดยไม่คำนึงถึงต้นทุน โดยบอกว่ารายละเอียดที่เผยแพร่ของกรณี Hugging Face ไม่สนับสนุนกรอบนั้น เขายังแยกสองหมวดความเสี่ยง — เอเจนต์อัตโนมัติที่ไม่สอดคล้อง เทียบผู้ไม่หวังดีที่ใช้ประโยชน์จากโมเดล — โดยบอกว่า OpenAI ลงทุนป้องกันทั้งสอง รวมถึงการบล็อกการขโมยข้อมูลประจำตัวและทราฟฟิกที่ออกแบบเพื่อล้วงความสามารถที่ถูกจำกัด และแยกระบุการใช้อาวุธชีวภาพในทางที่ผิดเป็นความเสี่ยงต่อการดำรงอยู่ที่ต้องการความพยายามทั้งอุตสาหกรรม

05 ระบบนิเวศโอเพนซอร์สและวัฒนธรรมภายใน

Sottiaux ให้เหตุผลว่า OpenAI รู้สึกถึงความรับผิดชอบลึกซึ้งเมื่อให้บริการผู้ใช้ราวหนึ่งพันล้านคน และเสนอว่าสแตกความปลอดภัยของ OpenAI อาจขยายไปยังโมเดลโอเพนซอร์สในที่สุด (อ้างความร่วมมือกับ Baseten) เพราะที่มาของการฝึกโมเดลเหล่านั้นโปร่งใสน้อยกว่า เรื่องการนำภายใน OpenAI เขาบรรยายวัฒนธรรม Slack แบบเปิดที่มีช่องถกเถียงฉับพลันและ Q&A สม่ำเสมอกับ Sam และ Greg โดยเทียบในเชิงบวกกับประสบการณ์ก่อนหน้าที่ DeepMind ซึ่งเขาบอกว่าการถกเถียงเปิดเช่นนั้นรักษาได้ยากกว่า เขาปิดด้วยการแสดงความมองโลกในแง่ดีว่า AI อาจปลดปล่อยผู้คนจากการติดโทรศัพท์/หน้าจอแบบบังคับภายในปีหน้า ขณะแสดงความกังวลว่าเทคโนโลยีอาจถูกใช้เพื่อรวมอำนาจและผลตอบแทนแทนที่จะเป็นประโยชน์แก่มนุษยชาติอย่างกว้างขวาง

01 ทราฟฟิกเอเจนต์ระเบิดเร็วกว่าที่คาด

02 โมเดลธุรกิจอินเทอร์เน็ตใหม่และปัญหาการชำระเงิน

เพราะเอเจนต์ไม่คลิกโฆษณาและสามารถแชร์การสมัครเดียวข้ามผู้ใช้จำนวนมาก Prince ให้เหตุผลว่าโมเดลที่ขับเคลื่อนด้วยโฆษณาซึ่งเลี้ยงอินเทอร์เน็ตมา 30 ปีกำลังพังทลาย เขาวางกรอบเป็นปัญหา tragedy of the commons: ด้วยต้นทุนส่วนเพิ่มเป็นศูนย์ เอเจนต์จะขูดข้อมูลไม่จำกัด (ตัวอย่างของเขา: สแกนเมนูหนึ่งพันรายการหรือต้นฉบับจีนปี 1318 ที่คลุมเครือเพื่อตอบคำถามมื้อกลางวัน) ทางแก้ที่เขาเสนอคือไมโครเพย์เมนต์ต่อการเข้าถึง อาจเป็นหนึ่งในพันของเพนนี ไหลจากบริษัท AI กลับไปยังแหล่งเนื้อหาเพื่อครอบคลุมต้นทุนการให้บริการ โดยบริษัทสื่อสามารถเรียกพรีเมียมเพื่อจ่ายนักข่าว Cloudflare เห็นตัวเองเป็นผู้จับคู่ โดยระบุว่า 80% ของบริษัท AI ขนาดใหญ่เป็นลูกค้าของตนอยู่แล้วควบคู่กับสัดส่วนมหาศาลของเว็บ ขนาดที่ต้องการ — ~10 ล้าน TPS ในวันแรก 100 ล้าน+ เมื่อโตเต็มที่ — คือเหตุผลที่ Prince บอกว่ากลไกฉันทามติของบล็อกเชนปัจจุบันช้าเกินไป; Cloudflare ไม่ผูกมัดว่าทางแก้จะเป็นบล็อกเชน สร้างภายใน หรือฐานข้อมูลปกติ

Prince ประมาณว่าการใช้จ่ายของเอเจนต์อาจแตะ $1,200 ต่อผู้บริโภคสหรัฐฯ ต่อปี น่าจะเบี่ยงมาจากงบตามดุลพินิจอย่างการสมัคร Netflix — สระที่เขาให้เหตุผลว่าจะผลักเอเจนต์ให้แข่งกันหาแหล่งข้อมูลคุณภาพสูงสุดและน่าเชื่อถือที่สุด ไม่ใช่แข่งลงก้นบ่อ เพราะต้นทุนสลับระหว่างเอเจนต์ (ChatGPT, Claude, Grok) ต่ำ เขากังวลมากกว่าเรื่องโลกกำลังพัฒนา ที่ผู้ใช้ที่ไม่มีงบ $1,200 น่าจะได้รับบริการจากเอเจนต์ที่มีโฆษณาสนับสนุน ซึ่งเขากลัวว่าอาจคล้ายรูปแบบโฆษณาแบบน่าขนลุกแนว Black Mirror ที่แสดงในโฆษณา Super Bowl ของ Anthropic แยกกัน Prince กังวลว่าการขาดอารมณ์และเวลาวิจัยไม่จำกัดของเอเจนต์ทำให้ธุรกิจขนาดเล็กและผู้เข้าตลาดใหม่เสียเปรียบ เพราะเอเจนต์เอื้อผู้ที่มีรอยเท้าข้อมูลที่ก่อตั้งมานานที่สุด — เขาบอกว่าทางแก้ยังไม่ชัดแต่จำเป็นเพื่อหลีกเลี่ยงโลกที่ถูกครอบงำโดยกลุ่มบริษัท AI สื่อ และพาณิชย์ขนาดใหญ่ห้าแห่ง เขาสงสัยว่าการกระจายศูนย์อย่างเดียวแก้ปัญหานี้ได้ โดยให้เหตุผลว่าตลาดและเครือข่ายรวมศูนย์ตามธรรมชาติเมื่อเวลาผ่านไปไม่ว่าสถาปัตยกรรมพื้นฐานจะเป็นอย่างไร เว้นแต่ผู้เข้าใหม่จะได้รับการเอื้อให้ชนะความไว้วางใจโดยเฉพาะ

เมื่อถูกถามถึงความกลัวความล้มเหลวของโครงสร้างพื้นฐานที่ขับเคลื่อนด้วย AI แบบหายนะ Prince บอกว่าความตระหนักไม่ใช่ปัญหา — เขาคิดว่าสาธารณชนหวาดระแวงเกินไปแล้วและควรมีเสียงที่อธิบายประโยชน์ของ AI มากขึ้น เขาคาดว่าสองปีข้างหน้าจะขรุขระด้วยเหตุการณ์น่ากลัว (การหลอกลวง และเหตุการณ์ความปลอดภัยไซเบอร์อย่างกรณี OpenAI และ Hugging Face ที่เขาอ้าง) แต่คาดว่าเหตุการณ์เหล่านี้จะลดลงอย่างมากเมื่อการตรวจสอบโค้ดที่ AI ช่วยแก้บั๊กซอฟต์แวร์ที่แฝงมานาน โดยอ้างประสบการณ์ของ Cloudflare เองที่พบและแก้บั๊กน้อยลงเมื่อเวลาผ่านไป เขายกตัวอย่างงานนิยายวิทยาศาสตร์ (Andy Weir, Star Trek, Terminator) เป็นการเปรียบเทียบหลวม ๆ เตือนไม่ให้ยึดติดกับเรื่องเล่าดิสโทเปียเกินไปขณะยังเอาความเสี่ยงจริงอย่างจริงจัง

05 รางการชำระเงิน ความเป็นส่วนตัว และการฟื้นของสื่อ

เรื่องคริปโตโดยเฉพาะ Prince บอกว่าสเตเบิลคอยน์สมเหตุสมผลสำหรับการย้ายเงินเข้าออกระบบนี้ แต่ Cloudflare จะไม่เลือกผู้ชนะบล็อกเชน โดยวางตัวเป็นชั้นกลางที่เป็นกลางสนับสนุนรางใดก็ตามที่สำเร็จ (ETH, Bitcoin, สเตเบิลคอยน์ใด ๆ) เขาให้เหตุผลว่าเอเจนต์ที่ทำหน้าที่เป็นพร็อกซีอาจฟื้นความเป็นส่วนตัวอย่างขัดแย้ง คล้ายที่ Private Relay ของ Apple แยก IP address ออกจากตัวตนรายบุคคล เพราะเอเจนต์ที่ทำธุรกรรมในนามของคุณอาจไม่จำเป็นต้องเปิดเผยว่าคุณเป็นใคร ท้ายที่สุด Prince วางกรอบโอกาสว่าเป็นการเปลี่ยนอินเทอร์เน็ตจากเศรษฐกิจความสนใจ (ให้รางวัลเนื้อหาที่กระตุ้นโดพามีนหรือคอร์ติซอล) ไปสู่เศรษฐกิจที่บริษัท AI จ่ายเฉพาะสำหรับข้อมูลที่ไม่ซ้ำและน่าเชื่อถือซึ่งเติมช่องว่างในความรู้ของโมเดลภาษาใหญ่ — ยกตัวอย่างการซื้อหนังสือพิมพ์ Park City, Utah ของเขาเอง (จำหน่าย 8,000) ซึ่งเขาคาดว่าจะหารายได้ปีนี้จากการอนุญาตให้ AI มากกว่าจากโฆษณาดิจิทัล
