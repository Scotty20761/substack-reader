🟢 รีวิว NVDA FY27Q3: ปรับเพิ่มไกด์แนนซ์การเติบโต FY2028 แต่การกลับมาของ Jensen Huang ยังคือกุญแจสำคัญ

นับจากรายงานพรีวิวของเรา NVIDIA มีความเคลื่อนไหวสำคัญหลายเรื่อง Jensen Huang ลาออก และบอร์ดแถลงตั้งแต่ต้นการประชุมผลประกอบการว่าไม่มีแผนจะแต่งตั้งเขากลับมาเป็น CEO บอร์ดเริ่มกระบวนการสรรหา CEO อย่างเป็นทางการ ทั้งผู้สมัครภายในและภายนอก พร้อมตั้งคณะกรรมการด้านความมั่นคงแห่งชาติและการควบคุมการส่งออก (National Security and Export Control Committee) ส่วนผลประกอบการระยะใกล้ออกมาเหนือความคาดหมาย รายได้ FY27Q3 อยู่ที่ $115.8 พันล้านดอลลาร์ (+20.4% QoQ) และไกด์แนนซ์รายได้ FY27Q4 อยู่ที่ $130 พันล้านดอลลาร์ ± 3% ไกด์แนนซ์การเติบโตของรายได้ FY2028 ยังถูกปรับขึ้นจาก 70% เป็นประมาณ 75% Kress ทำสิ่งที่ไม่ปกติด้วยการพูดปลอบใจพนักงานระหว่างการประชุม และยอมรับว่ามีความเห็นไม่ลงรอยกันภายในองค์กร ซึ่งสะท้อนความท้าทายในการรักษาบุคลากรหลักไว้ เรายังเชื่อเหมือนเดิมว่า การที่ Jensen Huang จะกลับมาหรือไม่ เป็นปัจจัยสำคัญต่อความสามารถในการแข่งขันของ NVIDIA ในอนาคต หากขาด Founder Mode แล้ว NVIDIA อาจพบว่ายากขึ้นในระยะยาวที่จะรักษาความสามารถในการแข่งขันของโรดแมปผลิตภัณฑ์ และความได้เปรียบจากการผสานระบบนิเวศซัพพลายเชนเอาไว้

บทสรุปAbstract
🔄 ผู้นำเปลี่ยน แต่ตัวเลขยังไปต่อ — Jensen Huang ลาออก และบอร์ดไม่มีแผนแต่งตั้งกลับ พร้อมเริ่มสรรหา CEO ใหม่และตั้งคณะกรรมการด้านความมั่นคงแห่งชาติและการควบคุมการส่งออก ขณะที่รายได้ FY27Q3 ยังออกมาที่ $115.8 พันล้านดอลลาร์ (+20.4% QoQ) เหนือความคาดหมาย

01Earnings Highlights — ไฮไลต์ผลประกอบการ

Key points
  • Data Center $108 พันล้านดอลลาร์ (+21% QoQ) โดย Hyperscale $60 พันล้านดอลลาร์ และ backlog คลาวด์ขึ้นไปที่ $2.5 ล้านล้านดอลลาร์
  • GM FY27Q3 อยู่ที่ 74.9% แล้วลดเหลือ 71%–72% ใน FY27Q4 ก่อนฟื้นเป็น 72%–73% ใน FY2028
  • Vera Rubin ทำรายได้เกือบ $20 พันล้านดอลลาร์ในไตรมาสแรก และ inference ต่อวัตต์สูง 10x ของ GB300
  • ราคา Token ลดเกือบ 60% ดันการใช้ OpenRouter ขึ้น 35x YoY และดันราคาเช่า GPU สูงขึ้น

แรงส่งของ Data Center และจุดต่ำสุดของอัตรากำไรขั้นต้นที่ยืนยันแล้ว: รายได้ Data Center ใน FY27Q3 อยู่ที่ $108 พันล้านดอลลาร์ (+21% QoQ) โดยเป็นรายได้จากกลุ่ม Hyperscale $60 พันล้านดอลลาร์ (+23% QoQ) ส่วน backlog ของผู้ให้บริการคลาวด์เพิ่มขึ้น $500 พันล้านดอลลาร์ QoQ ไปอยู่ที่ $2.5 ล้านล้านดอลลาร์ ไกด์แนนซ์ FY27Q4 รวมสัปดาห์ที่เพิ่มเข้ามาอีกหนึ่งสัปดาห์ ขณะที่รายได้จาก Hopper รุ่นเฉพาะตลาดจีนคาดว่าจะลดลงเหลือศูนย์ (จาก $2.4 พันล้านดอลลาร์ใน FY27Q3) อัตรากำไรขั้นต้นแบบ non-GAAP ของ FY27Q3 อยู่ที่ 74.9% ส่วนไกด์แนนซ์อัตรากำไรขั้นต้น FY27Q4 ลดลงเหลือ 71%–72% เพราะต้นทุนที่เกี่ยวข้องกับการส่งมอบออร์เดอร์รุ่นเก่า (OpEx แบบ non-GAAP ราว $10.7 พันล้านดอลลาร์) คาดว่าอัตรากำไรขั้นต้นจะฟื้นกลับเป็น 72%–73% ใน FY2028 เมื่อราคาใหม่เริ่มมีผล

ความคืบหน้าของผลิตภัณฑ์ และราคาเช่า GPU ที่สูงขึ้น: Vera Rubin สร้างรายได้เกือบ $20 พันล้านดอลลาร์ในไตรมาสแรกของการส่งมอบเชิงการผลิต โดยผลผลิตการอนุมาน (inference) ต่อวัตต์สูงถึง 10x ของ GB300 สวิตช์ CPO เข้าสู่การผลิตในปริมาณมากแล้ว ส่วน Rubin Ultra (2027) และ Feynman (2028) ยังเป็นไปตามกำหนด ตั้งแต่เดือนพฤษภาคม ราคา Token ลดลงเกือบ 60% ซึ่งผลักให้การใช้งานรายสัปดาห์ของ OpenRouter เพิ่มขึ้น 35x YoY (งานแบบ Agentic คิดเป็นราว 80%) การเพิ่มขึ้นนี้ยกอัตราการใช้งานของพลังประมวลผลขึ้น และดันราคาเช่า GPU ให้สูงขึ้น ราคาต่ออายุแบบหลายปีของ GPU Hopper สูงขึ้นถึง 2x ของราคาเดิม ขณะที่ราคาเช่า B300 เพิ่มขึ้นมากกว่า 60% นับตั้งแต่เปิดตัว ดีมานด์แบบ Agentic ยังคาดว่าจะทำให้รายได้ CPU ใน FY2028 เพิ่มขึ้นมากกว่าเท่าตัว

02Share Repurchases — การซื้อหุ้นคืน

Key points
  • FY27Q3 คืนผู้ถือหุ้น $28 พันล้านดอลลาร์ ($22 พันล้านดอลลาร์ซื้อหุ้นคืน + $6 พันล้านดอลลาร์ปันผล)
  • บอร์ดอนุมัติเพิ่มวงเงินซื้อคืน $150 พันล้านดอลลาร์ ซึ่งเป็นสถิติสูงสุด
  • ตั้งแต่ FY27Q4 FCF ส่วนเกินหลังการใช้เชิงกลยุทธ์จะคืนผู้ถือหุ้น 100%

ผลตอบแทนรวมต่อผู้ถือหุ้นใน FY27Q3 อยู่ที่ $28 พันล้านดอลลาร์ ($22 พันล้านดอลลาร์เป็นการซื้อหุ้นคืน และ $6 พันล้านดอลลาร์เป็นเงินปันผล) โดยอัตราการคืน FCF สะสมปีนี้ (YTD) อยู่ที่ 65% ในไตรมาสนี้บอร์ดอนุมัติเพิ่มวงเงินซื้อหุ้นคืนอีก $150 พันล้านดอลลาร์ ซึ่งเป็นสถิติสูงสุด วงเงินที่เหลือ ณ สิ้นไตรมาสอยู่ที่ $227 พันล้านดอลลาร์ และฝ่ายบริหารวางแผนจะใช้ให้หมดภายในสิ้น FY2028 ตั้งแต่ FY27Q4 เป็นต้นไป FCF ส่วนเกินหลังหักการใช้เชิงกลยุทธ์แล้ว จะถูกคืนให้ผู้ถือหุ้น 100%

04Analyst Independence Statement — คำแถลงความเป็นอิสระของนักวิเคราะห์

มุมมองที่แสดงในรายงานนี้สะท้อนความเห็นส่วนตัวและเป็นอิสระของนักวิเคราะห์เกี่ยวกับหลักทรัพย์และผู้ออกหลักทรัพย์ที่กล่าวถึงในที่นี้อย่างถูกต้อง ค่าตอบแทนของนักวิเคราะห์ไม่เคยเกี่ยวข้อง ไม่เกี่ยวข้อง และจะไม่เกี่ยวข้อง ไม่ว่าทางตรงหรือทางอ้อม กับคำแนะนำหรือมุมมองเฉพาะเจาะจงที่แสดงในรายงานนี้ บริษัทยึดถือขั้นตอนการปฏิบัติตามกฎระเบียบอย่างเคร่งครัด เพื่อรับรองความถูกต้องสมบูรณ์ ความปลอดภัย และความชอบด้วยกฎหมายของแหล่งข้อมูลและสารสนเทศที่ใช้

05About FUNDA — เกี่ยวกับ FUNDA

06No Investment Advice and Report Neutrality — ไม่ใช่คำแนะนำการลงทุน และความเป็นกลางของรายงาน

เนื้อหาของรายงานนี้และข้อมูลที่ปรากฏในรายงานมีไว้เพื่อให้ข้อมูลเท่านั้น ไม่ถือเป็นคำแนะนำการลงทุน หรือเป็นฐานสำหรับการตัดสินใจทางธุรกิจ มุมมองที่แสดงในที่นี้เป็นเพียงความเห็นส่วนตัวของผู้เขียนแต่ละท่าน ณ ช่วงเวลาหนึ่งโดยเฉพาะ และไม่ได้สะท้อนจุดยืนของ FUNDA ในฐานะแพลตฟอร์มที่ดำเนินงานอย่างอิสระ FUNDA รักษาสถานะบุคคลที่สามที่เป็นกลาง และไม่ให้การรับประกันใดๆ ทั้งโดยชัดแจ้งหรือโดยนัย เกี่ยวกับความถูกต้อง ความครบถ้วน หรือความเหมาะสมในการใช้งานของมุมมองดังกล่าว

ไม่ใช่การเสนอขายหรือชักชวน: รายงานนี้ไม่ถือเป็นการเสนอ การชักชวน คำแนะนำ หรือคำปรึกษาให้ซื้อ ขาย หรือถือหลักทรัพย์หรือเครื่องมือทางการเงินใดๆ และไม่ใช่คำปรึกษาด้านกฎหมาย ภาษี หรือการบัญชี

ข้อมูลจากบุคคลที่สาม: ข้อมูลของบุคคลที่สามทั้งหมดที่อ้างอิงในรายงานนี้มาจากแหล่งสาธารณะหรือแหล่งที่ได้รับอนุญาต บริษัทไม่ให้การรับรองหรือรับประกันใดๆ ทั้งโดยชัดแจ้งหรือโดยนัย เกี่ยวกับความถูกต้องหรือความครบถ้วนของข้อมูลเหล่านั้น

ไม่มีส่วนร่วมในการตัดสินใจ: บริษัทไม่มีส่วนร่วม ไม่ว่าทางตรงหรือทางอ้อม ในกระบวนการตัดสินใจลงทุนของลูกค้าหรือผู้อ่าน ผู้อ่านควรตัดสินใจลงทุนด้วยตนเองโดยอิงวัตถุประสงค์การลงทุนและสถานะทางการเงินของตน และควรปรึกษาที่ปรึกษาด้านการเงินหรือกฎหมายที่เป็นมืออาชีพก่อนทำธุรกรรมใดๆ

07Timeliness Statement — คำแถลงเรื่องความทันสมัยของข้อมูล

เมื่อพิจารณาว่าสภาพแวดล้อมของตลาดและแนวโน้มทางเทคโนโลยีเปลี่ยนแปลงอย่างรวดเร็ว รายงานนี้สะท้อนสภาวะตลาด ณ วันก่อนหน้าวันที่เผยแพร่ ข้อมูลที่เกี่ยวข้องอาจล้าสมัยเมื่อเวลาผ่านไป FUNDA ไม่มีหน้าที่ต้องอัปเดตเนื้อหาของรายงานนี้แบบเรียลไทม์

08Intellectual Property, Confidentiality, and Restrictions on Commercial Use — ทรัพย์สินทางปัญญา การรักษาความลับ และข้อจำกัดการใช้เชิงพาณิชย์

รายงาน ข้อมูล โมเดล และเนื้อหาทั้งหมดที่บริษัทจัดทำ เป็นทรัพย์สินทางปัญญาที่เป็นกรรมสิทธิ์เฉพาะของบริษัท และได้รับความคุ้มครองตามกฎหมายลิขสิทธิ์และทรัพย์สินทางปัญญา

ความเป็นเจ้าของสิทธิ: เว้นแต่จะระบุไว้เป็นอย่างอื่นโดยชัดแจ้งในข้อตกลงเป็นลายลักษณ์อักษร สิทธิในทรัพย์สินทางปัญญาทั้งหมด (รวมถึงลิขสิทธิ์) ที่เกิดจากหรือเกี่ยวข้องกับรายงานนี้ เป็นของบริษัทแต่เพียงผู้เดียว

การใช้ที่ได้รับอนุญาต: ลูกค้าสถาบันอาจใช้รายงานนี้ภายในองค์กรได้ ภายในขอบเขตที่นโยบายกำกับดูแลภายในของตนอนุญาต แต่ห้ามเปิดเผยหรือแบ่งปันให้บุคคลที่สามโดยเด็ดขาด

ห้ามใช้เชิงพาณิชย์: หากไม่ได้รับความยินยอมเป็นลายลักษณ์อักษรอย่างชัดแจ้งจากบริษัทล่วงหน้า บุคคลหรือนิติบุคคลใดไม่อาจทำซ้ำ เผยแพร่ซ้ำ แจกจ่าย ขายต่อ จัดรูปแบบใหม่เพื่อจำหน่าย หรือใช้รายงานนี้หรือส่วนใดส่วนหนึ่งเพื่อวัตถุประสงค์เชิงพาณิชย์หรือหากำไรไม่ว่ารูปแบบใด

การดำเนินคดี: บริษัทขอสงวนสิทธิ์ที่จะใช้มาตรการทางกฎหมายและเรียกร้องสิทธิ์ทั้งหมดที่มี ต่อการใช้เชิงพาณิชย์โดยไม่ได้รับอนุญาต การเผยแพร่ซ้ำ หรือการละเมิดสิทธิในทรัพย์สินทางปัญญาของบริษัท
