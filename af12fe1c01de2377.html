📰 TMTB: ความคิดก่อน S-1 ของ Anthropic

โดย TMT Breakout | 22 ต.ค. 2026

6 เรื่องที่การทำโมเดล Anthropic ทำให้เราต้องหยุดคิด; รายละเอียดโมเดล ชาร์ต และอื่น ๆ

📋 ที่มา

ตัวเลข ARR เดือนกันยายนของ Anthropic เมื่อสัปดาห์ที่แล้ว (~$70B เทียบกับที่คาดไว้ $78–$80B) เติมเชื้อแห่งความสงสัยให้เทรด AI ที่ขุ่นมัวอยู่แล้ว โดยเฉพาะเรื่องวิถีของ ARR ของแล็บทั้งหลายไปจนถึงปี 2028

เราใช้เวลาหนึ่งสัปดาห์ที่ผ่านมาพยายามสร้างโมเดล Anthropic จากรายงานร่าง S-1 ที่รั่วออกมา ข่าวจากสื่อ ความเห็นของนักลงทุน และข้อมูลการใช้งาน ทั้งกระบวนการช่วยให้เราคิดเรื่องปัญหาและตัวขับเคลื่อนหลายอย่างได้ละเอียดขึ้น เดิมเราตั้งใจรอฉบับรายสัปดาห์ แต่อยากปล่อยก่อนที่ S-1 จะออก เพื่อช่วยวางกรอบและให้บริบทกับหลายประเด็นที่น่าจะถูกพูดถึงมากขึ้นในวันข้างหน้า

นี่คือที่ที่เราลงเอยกับตัวเลข:

🧠 6 เรื่องที่การทำโมเดล Anthropic ทำให้เราคิด

1. "อุปสงค์ไม่จำกัด" หมายความว่าอย่างไร?

ในครึ่งปีแรก ทุก GW ที่ Anthropic เพิ่มถูกขายหมด และ ARR พุ่งจาก ~$9B เมื่อธันวาคมปีที่แล้วเป็น ~$65B ภายในเดือนกรกฎาคม จากนั้นไตรมาส 3 ก็ปล่อยกำลังการผลิตจริงออกมา เมื่อการ distillation ถูกปิดกั้น, META ย้ายงานไปใช้โมเดลของตัวเอง และ MSFT ลดการใช้ภายใน ตามตัวเลขของเรา รายการครั้งเดียวเหล่านี้ลดลงจากราว ~$10.6B ของ ARR ในเดือนกรกฎาคมเหลือ ~$4.5B ในเดือนกันยายน

ถ้าอุปสงค์ไม่จำกัดจริง ลูกค้าที่จ่ายเงินน่าจะดูดกำลังส่วนเกินนั้นไปที่ราคาตลาดภายในไม่กี่สัปดาห์ (โดยมีข้อแม้ว่าดีลองค์กรใช้เวลาเซ็น) แต่ไม่เป็นเช่นนั้น Anthropic ลดราคา (Opus 5.5 −20%, cache reads −60%, Haiku 5.5 ~−75%) และให้สมาชิก Pro และ Max ใช้งานได้มากขึ้น: การวัดจากบุคคลที่สามชี้ว่าโควตารายสัปดาห์ของแผน Max $200 เพิ่มจาก ~$1,400 เป็น ~$1,750 ของการใช้งานเทียบเท่า API ระหว่างปลายเดือนกันยายนถึงกลางเดือนตุลาคม ทั้งที่ข้อมูลของ Ramp ชี้ว่า Anthropic กลับมาครองส่วนแบ่งค่าใช้จ่าย 60%+ ใกล้เคียงกับก่อนเหตุการณ์ Astra ถ้ากำลังประมวลผลตึงจริง ทำไม Anthropic จึงให้โควตามากขึ้นแก่สมาชิก แทนที่จะโยกไปเป็นค่าใช้จ่าย API ที่สร้าง ARR?

2. ปริมาณไล่ตามการลดราคาได้เร็วแค่ไหน?

การลดราคาเดือนกันยายน–ตุลาคม (Opus 5.5 −20%, cache reads −60%, Haiku 5.5 ~−75%) หัก ARR เดือนตุลาคมราว ~$10B ที่ปริมาณคงที่ตามประมาณการของเรา ข้อมูลของ Ramp บอกว่าปริมาณกำลังกลับมาเร็วกว่านั้นแล้ว ค่าใช้จ่ายโทเคนของ OpenAI + Anthropic เพิ่ม 23% ในสี่สัปดาห์จนถึง 11/10 บนปริมาณที่เพิ่ม 52% เรารู้ว่า OAI เห็นการใช้งาน Luna 10–14 เท่าจากการลดราคา 80% ในเดือนกันยายน การลด 20% ย่อมจุดการใช้งานได้น้อยกว่ามาก เราตั้งโมเดลให้ ~$8B กลับมาภายในเดือนธันวาคม โดยแบ่งเฟส 40/40/20 ตลอดตุลาคม–ธันวาคม เป็นผลหักสุทธิจากราคาใน Q4 ราว ~$2B ของ ARR อยากได้รายละเอียดเรื่องนี้จากฝ่ายบริหารเพิ่มอีก

3. กองเรือ (fleet) ทำเงินจริงสักเท่าไร?

เราประมาณว่า ~38% ของกองเรือของ Anthropic ทำ inference ในวันนี้ ที่เหลือคือ training, post-training และ RL เราโมเดลว่า ~70% ของ inference serving รองรับลูกค้าที่จ่ายเงิน ที่เหลือคือฟรีเทียร์ การใช้ภายใน และ evals ดังนั้นประมาณหนึ่งในสี่ของกองเรือสร้างรายได้

SA บอกว่า subscription ใช้ compute ด้าน inference เกิน 40% แต่ให้รายได้ไม่ถึง 20% และ GW ที่ขายเป็น API ให้ ARR ราว ~$80B เทียบกับ ~$27–30B จาก subscription

เราประมาณว่า Anthropic ได้ ARR ~$56–58B ต่อ inference GW และ ~$18–22B ต่อ GW ของ compute ทั้งหมด

4. ถ้าแล็บหนึ่งเทรนน้อยลง คนอื่นจะตามทันไหม?

คันโยกอัตรากำไรที่ใหญ่ที่สุดไม่ใช่การซื้อ GW เพิ่ม แต่คือการใช้ GW ที่ Anthropic มีอยู่แล้วให้มากขึ้นเพื่อรองรับลูกค้า แทนที่จะใช้เทรนโมเดล กรณีกระทิงด้าน inference ของเรามี GW เท่าฐาน แต่ใช้ 55–62% ของกองเรือกับ inference ในปี 2027–28 เทียบกับ 44–50% ในกรณีฐาน ค่า compute ของ FY28 เท่าเดิมที่ ~$149B แต่ส่วนที่ทำเงินมากขึ้น ทำให้อัตรากำไรจากการดำเนินงานปรับแล้ว FY28 อยู่ที่ ~24% แทน ~5%

การเติมกำลังส่วนเกินนั้นหมายถึง ARR ใหม่สุทธิ ~$9.9B ต่อเดือนในปี 2027 เทียบกับ $6.5B ในกรณีฐาน และน่าจะต้องลดราคาลงเพื่อไปถึงจุดนั้น

ส่วนแบ่ง inference ที่เพิ่ม 5% ส่งผลมาก: ARR เพิ่มอีก ~$10B ภายในสิ้นปี 2027:

อย่างไรก็ตาม เราเห็นจากการเปิดตัว Astra ของ OpenAI ว่าคู่แข่งไล่ตามที่แนวหน้าได้เร็วแค่ไหน ตามประมาณการของเรา มันดึง ARR ของ Anthropic ไป ~$4–6B ในไม่กี่สัปดาห์ของเดือนกันยายน และ Opus 5.5 ดึงกลับมาได้ ~$4.5B เร็วพอกัน ใครก็ตามที่ชะลอการเทรนก่อนเพื่อแสดงอัตรากำไร เสี่ยงเสียตำแหน่งนำและราคาที่มาพร้อมกัน ผมจึงไม่คาดว่าใครจะกะพริบตา เราคิดว่าตลาดก็คิดเช่นนี้ และจะลงโทษการชะลอเทรนใด ๆ ในตอนนี้ การเทรนยังกินครึ่งหนึ่งหรือมากกว่าของกองเรือจนถึงปี 2028 ในกรณีฐานของเรา

5. ราคาลดได้เร็วแค่ไหน?

เราโมเดลให้ราคาโทเคนระดับแนวหน้าลดลง ~45–55% ต่อปี (ราคา input ของ Opus ไป $15 → $5 (Opus 4.5, พ.ย. 2025) → $4 (Opus 5.5, 22/9) ต่อล้านโทเคน ลดลง ~73% ในหนึ่งปี … ในข้อมูลของ Ramp สิ่งที่ลูกค้า Anthropic จ่ายต่อโทเคนลดลง ~40% จากปลายกรกฎาคมถึงต้นตุลาคม) ชิปแต่ละรุ่นเพิ่มโทเคนต่อ GW ราวสองเท่า และงานเปลี่ยนไปเป็นงาน agentic ที่ยาวขึ้น ซึ่งชดเชยได้เกือบทั้งหมด เราจึงให้ ARR ต่อ inference GW ลดลงเพียง ~10–15% ต่อปี อยากดูว่าคนอื่นโมเดลตรงนี้อย่างไร

ถ้าราคาลดเร็วกว่าโทเคนต่อ GW ที่เพิ่ม แล็บต้องการ GW มากขึ้นมากและ demand มากขึ้นมาก เพียงเพื่อเติบโต กรณีหมีของเรา (ARR ต่อ inference GW −35% ในปี 2027, GW น้อยลง, demand อ่อนลง) ให้ ARR สิ้นปี 2027 ที่ ~$103B เทียบกับ $164B ในกรณีฐาน เป็นปัจจัยแกว่งใหญ่ที่นักลงทุนควรโฟกัสเป็นหลัก

6. ถ้าเดือนสิงหาคมพลาดขนาดนั้น แล้วปี 2027–28 ล่ะ?

ตลอดฤดูร้อน นักลงทุนบอกสื่อว่า Anthropic จะปิดปี 2026 ด้วย ARR สูงกว่า $100B มาก กลางเดือนกันยายน NYT รายงานว่ากำลังเดินหน้าไปเกิน $100B ตอนนี้เราอยู่ที่ ~$86B สำหรับเดือนธันวาคม ต่ำกว่าประมาณการเหล่านั้น $14–34B ทั้งที่เป็นตัวเลขอีกไม่กี่เดือนข้างหน้า

นี่คือจุดสำคัญว่าทำไมผมคิดว่าตัวเลข ARR เมื่อสัปดาห์ที่แล้วสร้างปัญหาใหญ่ให้เทรดเซมิฯ AI ตลอด 9 เดือนแรกของปีที่ ARR ชนะคาด แล็บโยนตัวเลขรายได้อนาคตอะไรออกมาก็ได้ และตลาดกลืนหมด เมื่อพลาดครั้งนี้ ก็เกิดปัญหาความน่าเชื่อถือใหญ่ในการเชื่อสิ่งที่ฝ่ายบริหาร Anthropic พยายามปั้นบน roadshow และกับนักลงทุน (และเราคาดว่าจะเป็นการปั้นที่ดี) แล็บคือผู้ซื้อส่วนเพิ่มของ compute AI และนั่นคือเหตุผลที่ ARR ของแล็บเป็นประเด็นถกเถียงหลักของนักลงทุน นอกจากยกคำถามบางข้อข้างต้นแล้ว ที่สำคัญกว่าคือ การพลาดครั้งนี้ยกคำถามของทุกคำถามขึ้นมา: ว่า end demand มีอยู่จริงพอจะจ่ายค่าการก่อสร้างหรือไม่

จดหมายข่าวนี้เผยแพร่เพื่อวัตถุประสงค์ด้านข้อมูลและการศึกษาเท่านั้น ไม่มีส่วนใดเป็นคำแนะนำการลงทุนเฉพาะบุคคล คำแนะนำที่ปรับให้เหมาะกับสถานการณ์ของใครคนใดคนหนึ่ง คำเสนอ หรือการชักชวนให้ซื้อขายหลักทรัพย์หรือตราสารทางการเงินใด ๆ จดหมายข่าวนี้ไม่ใช่บริการให้คำปรึกษาด้านการลงทุน และไม่ก่อให้เกิดความสัมพันธ์แบบที่ปรึกษาหรือผู้ดูแลผลประโยชน์ระหว่างผมกับผู้อ่านคนใด

ผมซื้อขายหลักทรัพย์ที่กล่าวถึงที่นี่อยู่จริง และมักเป็นการเทรดระยะสั้น สถานะของผมอาจไม่สอดคล้องกับมุมมองที่เขียนไว้ และผมอาจซื้อหรือขายได้ทุกเมื่อ — รวมถึงทันทีก่อนหรือหลังเผยแพร่ — โดยไม่แจ้งหรืออัปเดต ราคาเป้าหมาย สถานการณ์ขาขึ้น/ขาลง และกรอบเวลาเป็นเพียงความเห็นเชิงอธิบาย ไม่ใช่คำมั่นว่าจะถือต่อ

สิ่งพิมพ์นี้สำหรับการใช้งานส่วนตัวของสมาชิกเท่านั้น ห้ามแจกจ่าย เผยแพร่ซ้ำ ส่งต่อ หรืออ้างอิงโดยไม่ได้รับอนุญาตเป็นลายลักษณ์อักษรล่วงหน้า ลิขสิทธิ์ © 2026 TMT Breakout สงวนลิขสิทธิ์

🎯 Key Takeaways

  1. 📉 ARR เดือนกันยายน ~$70B พลาดคาด $78–80B — เติมเชื้อความสงสัยให้เทรด AI ที่ขุ่นอยู่แล้ว โดยเฉพาะวิถี ARR ของแล็บถึงปี 2028
  2. 🧪 "อุปสงค์ไม่จำกัด" ถูกตั้งคำถาม — รายการครั้งเดียว (distillation ถูกปิด, META ย้ายไปโมเดลตัวเอง, MSFT ลดใช้ภายใน) ลดจาก ~$10.6B เหลือ ~$4.5B และ Anthropic ยังลดราคา/เพิ่มโควตาสมาชิก
  3. 💸 ลดราคา ~$10B ที่ปริมาณคงที่ — แต่ข้อมูล Ramp ชี้ว่าปริมาณกลับเร็ว (โทเคน +52% ขณะที่ค่าใช้จ่าย +23%); โมเดลให้ ~$8B กลับมาภายในธันวาคม (หักสุทธิ Q4 ~$2B)
  4. 🏭 มีเพียงราว 1 ใน 4 ของกองเรือที่ทำเงิน — ~38% ทำ inference และ ~70% ของนั้นรองรับลูกค้าจ่ายเงิน; ARR ต่อ inference GW ~$56–58B
  5. ⚖️ คันโยกกำไรคือสัดส่วน inference ไม่ใช่ GW เพิ่ม — กรณีกระทิง FY28 margin ~24% เทียบ ~5%; แต่ไม่มีแล็บไหนกล้าชะลอเทรนเพราะเสียแนวหน้า
  6. 📉 ราคาโทเคนลด ~45–55% ต่อปี — ARR ต่อ inference GW ลดเพียง ~10–15% เพราะ tokens/GW เพิ่ม; กรณีหมีทำให้ ARR สิ้นปี 2027 ~$103B เทียบ $164B ในกรณีฐาน
  7. 🔍 ปัญหาความน่าเชื่อถือ — ธันวาคมอยู่ที่ ~$86B ต่ำกว่าประมาณการ $100B+ ถึง $14–34B และคำถามใหญ่คือ end demand จ่ายค่าการก่อสร้างได้หรือไม่
