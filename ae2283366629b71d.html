02บทสรุปSummary

Key points
  • ดีมานด์ทั้ง Azure และ M365/Copilot แข็งแรงจากการเช็คที่ Ignite
  • CFO มั่นใจ ROIC ของ capex ทั่วพอร์ต — ทุกหมวดเหนือ WACC
  • exposure ต่อ frontier lab ทำให้ Azure ผันผวนได้มากขึ้น
  • ลูกค้าคุมต้นทุน AI token เข้ม แต่ยังหักลบเป็นการใช้จ่าย AI ปี 2027 ที่แข็งแรง

เราส่งทีมสองคนไปงาน Ignite งานใหญ่ของ Microsoft ที่ซานฟรานซิสโก ที่นั่นเราจัดประชุมกลุ่มระหว่าง CFO กับนักลงทุน จัดเซสชันนักลงทุนกับพาร์ทเนอร์รายใหญ่สามราย แล้วก็เดินคุยกับลูกค้าและพาร์ทเนอร์บนฟลอร์งานด้วย ภาพรวมคือ สัญญาณดีมานด์ทั้ง Azure และ M365/Copilot แข็งแรง — ประเด็นเดียวที่ออกมาแบบปนๆ คือเรื่องเล่าจากลูกค้าที่ระวังค่าใช้จ่ายด้าน AI token มากๆ เราให้เรตติ้ง Buy

🎙 ความเห็นของ CFO และ CEO

สิ่งที่เราได้จากการพบ CFO เป็นหลักคือ ความมั่นใจว่า Microsoft จะได้ ROIC สูงจากการใช้ capex ทั่วทั้งพอร์ต — ตั้งแต่การใช้ compute กับงานของตัวเอง (1P อย่าง Copilot) ซึ่ง ROI สูงสุด ไปจนถึง GPU as-a-service ที่น่าสนใจน้อยที่สุด แต่ก็ยังล็อกผลตอบแทนที่ดี สูงกว่า WACC ของ Microsoft อย่างชัดเจน ไม่มีความลังเลเลยทั้งเรื่องดีมานด์หรือซัพพลาย compute และไม่มีความลังเลเรื่อง ROIC — ในมุมผม นี่เปิดทางให้ capex ปี CY27 เติบโตได้อย่างแข็งแรง (ซึ่งเราสมมติไว้แล้ว) Microsoft บอกชัดว่า การมี exposure ต่อ frontier lab ที่สูงขึ้น/เติบโตขึ้น (ตอนนี้คือ OpenAI เป็นหลัก) ทำให้การเติบโตของ Azure ผันผวนได้มากขึ้น ส่วนข้อความจาก CEO เน้นที่โมเดล 1P ของ Microsoft การเพิ่มประสิทธิภาพ compute ให้มากขึ้น การยกระดับชุดผลิตภัณฑ์ security และการจำกัด exposure ด้าน compute ต่อพวก lab

🤝 สิ่งที่พาร์ทเนอร์เล่าให้เราฟัง

โทนจากพาร์ทเนอร์โดยรวมเป็นบวก ไม่ใช่แค่เรื่องการเติบโตของ Azure แต่ (ที่น่าแปลกใจ) กลับเป็นเรื่อง การเติบโตของจำนวน seat ของ Copilot และดีมานด์โซลูชัน cyber-security มากกว่า ซึ่งพาร์ทเนอร์หลายรายบอกว่าพุ่งขึ้นมาในช่วงไม่กี่เดือนหลัง การเช็คของเราไม่ได้ส่งสัญญาณว่าแผนใช้จ่ายด้าน AI ของบริษัทในปี 2027 จะชะลอลงเลย ถึงอย่างนั้น แม้แต่ Microsoft เองก็ยอมรับว่าลูกค้ากังวลว่าต้องบริหารค่าใช้จ่าย AI ให้ดีขึ้นเมื่อ AI ขยายสเกล พาร์ทเนอร์ชี้ว่าลูกค้าโฟกัสชัดมากกับการคุมต้นทุน AI โดยเฉพาะเมื่อโครงสร้างราคา software เปลี่ยนไปเป็นแบบคิดตามการใช้งาน (usage-based) ส่วนผสมของ "อยากปล่อย AI app/agent มากๆ" กับ "โฟกัสคุมต้นทุนหนักๆ" ยังคงหักลบออกมาเป็นการใช้จ่าย AI ที่คาดว่าจะแข็งแรงในปี 2027

04Exposure ต่อ OpenAI/Frontier LabsExposure to OpenAI/Frontier Labs

Key points
  • OpenAI ใช้จ่ายบน Azure ใน 1Q/Sept เท่ากับ 31% ของรายได้ Azure
  • exposure รวมต่อ lab สูงกว่า 31% มาก ผ่านลูกค้าองค์กรที่ซื้อผ่าน Foundry
  • CEO ไม่อยากสร้างเพื่อ lab แค่สองราย
  • CFO ยอมรับความผันผวนของ Azure ที่เพิ่มขึ้น

ในไตรมาส 1Q/Sept Microsoft บอกชัดว่าไตรมาส Sept ที่แข็งแรงของ OpenAI (คือแรงดึงของโมเดล Astra) แปลงเป็น upside ของ Azure ได้สองทาง ทางแรกผ่านการเติบโตแรงของ Azure Foundry เพราะบริษัทจำนวนมากซื้อโมเดล AI (ผ่าน API call) และผลิตภัณฑ์ผ่านพาร์ทเนอร์ hyperscaler ของตัวเอง นี่คือเหตุผลสำคัญที่เราอยู่ในช่วงหลายไตรมาสของการเร่งตัวแบบพิเศษของการเติบโตรายได้ hyperscaler และยอดเงินที่เพิ่มขึ้นต่อไตรมาส ทางที่สองคือผ่านส่วนแบ่งรายได้ OpenAI ที่จ่ายให้ Microsoft ทั้งสองกรณี อย่างที่ Microsoft พูด "เมื่อ OpenAI แข็งแรง มันดีต่อ Azure" สะท้อนในการเปิดเผยว่า OpenAI ใช้จ่าย $10 billion บน Azure ในไตรมาส 1Q/Sept เท่ากับ 31% ของรายได้ Azure แต่ exposure ของ Azure ต่อพวก lab สูงกว่านี้ เพราะ a) นี่เป็นแค่ OpenAI ส่วน Microsoft ก็มี exposure ต่อ lab อื่นด้วย และ b) ตัวเลข $10 billion นี้ไม่รวมกิจกรรมของบริษัทที่ทำสัญญากับ Azure (ผ่าน Foundry) เพื่อซื้อผลิตภัณฑ์ OpenAI เพราะในกรณีนี้ความสัมพันธ์ทางการค้าอยู่กับบริษัท ไม่ใช่กับ OpenAI exposure รวมของ Azure ต่อพวก lab สูงกว่า 31% มาก เราถามเรื่องนี้ทั้ง CEO และ CFO:

  • CEO: เรากดถาม CEO เรื่องความเห็นล่าสุดของเขาว่า "เราไม่อยากสร้างเพื่อ lab แค่สองราย" นี่คือการพูดถึงความต้องการกระจาย mix อย่างชัดเจน ด้วยหลายเหตุผล ทั้งเพื่อสร้างธุรกิจที่ยั่งยืน และเพื่อรับมือกับการที่พวก lab กำลัง integrate ลงมาในชั้น compute เอง
  • CFO: คำถามที่เราถาม CFO เน้นเรื่องการจัดการความผันผวน เพราะตอนนี้ผล Azure ในไตรมาสใดก็ตามอาจได้รับผลกระทบอย่างมีนัยจาก upside-downside ของผลประกอบการรายได้ของลูกค้า frontier lab CFO ไม่ได้แย้ง โดยบอกว่าการคาดการณ์ระดับราคาของ lab และจังหวะการเปิดตัวโมเดลใหม่ เพิ่มความผันผวนที่อาจเกิดกับการเติบโตของ Azure โดยเฉพาะเมื่อ Foundry มีสัดส่วนใน mix มากขึ้น ในมุมผม นี่น่าจะหมายถึง guidance Azure ที่ระมัดระวังขึ้นเล็กน้อย และเมื่อ/ถ้า Azure พลาดหรือชนะเป้า สัญชาตญาณแรกคือไปหาคำตอบที่ exposure และผลประกอบการของ lab

  1. ☁️ ดีมานด์ยังแรงทั้งสองขา — Azure และ M365/Copilot ส่งสัญญาณแข็งแรงจาก Ignite ไม่มีใครเห็นการชะลองบ AI ปี 2027 UBS คงเรตติ้ง Buy และราคาเป้าหมาย $700 (27x non-GAAP EPS CY28) เทียบราคา US$508.29 — ผลตอบแทนคาดการณ์ 38.5%
  2. 💸 ประเด็นเดียวที่ต้องจับตาคือ "การคุมต้นทุน token" — การเปลี่ยน Copilot เป็น usage-based ทำให้ CFO ฝั่งลูกค้ากังวล มีการถอยการใช้งาน และบางบริษัทตั้งเพดาน $20/$200 ต่อคนต่อเดือน แต่ภาพรวมยังหักลบเป็นการใช้จ่าย AI ที่แข็งแรง
  3. 🔗 Azure ผูกกับ frontier lab มากกว่าที่ตัวเลข 31% บอก — OpenAI จ่าย $10 billion บน Azure ใน 1Q/Sept แต่ exposure จริงสูงกว่านั้นมากผ่าน Foundry; CFO ยอมรับว่าความผันผวนของ Azure จะสูงขึ้น → guidance น่าจะระมัดระวังขึ้น
  4. ⚡ ความยืดหยุ่นในการจัดสรร compute คือ moat — เรียง ROIC: 1P (Copilot) > Foundry > GPU-as-a-service; ทุกหมวดยังเหนือ WACC ทำให้ Microsoft ต่างจาก neo-cloud และเปิดทางให้ capex CY27 โตต่อ
