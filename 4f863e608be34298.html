02โปรเจกต์ CPU กับ OpenAIOpenAI Custom CPU Project

Key points
  • Arm ไม่แสดงความเห็นเรื่องผลิตภัณฑ์ที่ยังไม่ประกาศ
  • โฟกัสตอนนี้อยู่ที่ AGI CPU — OpenAI เป็นลูกค้าที่ทำงานด้วยใกล้ชิด
  • ลูกค้า CPU มีครบทุกกลุ่ม: foundational model, on-prem server แบบดั้งเดิม และคลาวด์

🙋 คำถาม: มีความคืบหน้าอะไรบ้างกับโปรเจกต์ custom CPU ที่ Arm ทำร่วมกับ OpenAI?

💬 Arm: เอ่อ… ผมคงต้องบอกว่าเราแสดงความเห็นเรื่องผลิตภัณฑ์ที่ยังไม่ได้ประกาศไม่ได้ อืม คงต้องจบไว้แค่นั้นจริง ๆ น่าเสียดาย สิ่งที่ผมพูดได้คือตอนนี้โฟกัสของเราอยู่ที่ AGI CPU — OpenAI เป็นลูกค้าของเรา เราทำงานใกล้ชิดกับเขา และทำงานใกล้ชิดกับ — พาร์ทเนอร์ด้าน rack อีกจำนวนมากด้วย เรามีลูกค้า CPU ครบทุกกลุ่ม ตั้งแต่บริษัท foundational model ไปจนถึงบริษัทดั้งเดิมที่รันเซิร์ฟเวอร์ on-prem และรวมถึงกลุ่มคลาวด์บางรายด้วย เรื่องผลิตภัณฑ์ที่ยังไม่ประกาศ ขอจบไว้แค่นี้

03ข้อจำกัดด้านซัพพลายเชนSupply Chain Constraints

Key points
  • ไม่ใช่ "ปัญหา" แต่มีข้อจำกัดแน่นอน — ตามที่ Lip-Bu พูดบนเวที
  • คอขวดไม่ได้อยู่แค่เวเฟอร์หรือหน่วยความจำ แต่ลามทั้งห่วงโซ่ถึงซับสเตรตและวัสดุซับสเตรต
  • ซัพพลายเออร์เริ่มลงทุนเพิ่มกำลังการผลิตมา 6-8 เดือน กำลังการผลิตใหม่เข้าช่วงปลายปี 27-28
  • Arm เพิ่มซัพพลาย CPU สำหรับปีหน้าแล้ว แต่จะขายได้มากกว่านี้ถ้ามีของ

🙋 คำถาม: คุณไม่เห็นปัญหาซัพพลายเชนในการจัดหาของเลยหรือ หรือว่ามีแค่ฝั่ง CPU?

💬 Arm: ผมจะไม่เรียกว่า "ปัญหา" แต่มีข้อจำกัดไหม? มีแน่นอน ผมคิดว่า Lip-Bu ก็พูดไว้บนเวทีแล้วใช่ไหม — ถ้ามีซัพพลายมากกว่านี้ทั้งระบบ และผมไม่คิดว่ามันจำกัดอยู่แค่กำลังการผลิตเวเฟอร์หรือหน่วยความจำอีกต่อไปแล้ว มันกระจายไปทั้งห่วงโซ่ — ซับสเตรต วัสดุซับสเตรตที่ป้อนเข้ามาในส่วนนั้น ผู้เล่นทั้งหมดนี้ตึงตัวมาก สิ่งที่พวกเขาทำคือ ผมคิดว่าเขาเริ่มลงทุนเพิ่มกำลังการผลิตมาตลอด 6-8 เดือนที่ผ่านมา และผมคิดว่าเราจะเริ่มเห็นกำลังการผลิตนั้นทยอยเข้ามาราวปลายปี 27 ถึงปี 28 ในการประชุมผลประกอบการครั้งล่าสุด เราพูดถึงการที่เราเพิ่มซัพพลายสำหรับ CPU ของเราในปีหน้าแล้ว เราทำได้มากกว่านั้นไหม? ถ้าหาซัพพลายเพิ่มได้ เราจะทำได้มากกว่านี้ไหม? ฝั่งซัพพลายเชน — ได้แน่นอน แต่เราค่อนข้างหวังว่าตั้งแต่ปี 28 เป็นต้นไปจะเป็นจุดเปลี่ยนในเรื่องนี้

04วิวัฒนาการเชิงกลยุทธ์ — จาก IP สู่ซิลิคอนStrategic Evolution — From IP to Silicon

Key points
  • คนส่วนใหญ่ยังมอง Arm เป็นธุรกิจ licensing ล้วน ๆ
  • Arm มี 3 ตลาด: data center/cloud, edge และ physical AI
  • ตอนนี้มี 2 ธุรกิจ — licensing และธุรกิจชิป ซึ่งเริ่มจาก Arm AGI CPU
  • Arm อยากให้มองตัวเองเป็น foundational compute platform สำหรับ AI

🙋 คำถาม: ถ้าพวกคุณส่งสารได้หนึ่งข้อ ให้ถึงคนจำนวนมากอย่างได้ผลกว่านี้ สารนั้นคืออะไร? อะไรคือสิ่งที่อยากบอกผู้คนตอนนี้ — เรื่องที่สำคัญที่สุด

💬 Arm: ผมคิดว่าถ้ามองในระดับสูงที่สุด คนส่วนใหญ่น่าจะยังมอง Arm เป็นธุรกิจ licensing ล้วน ๆ และไม่ได้คิดถึง Arm จริง ๆ ในแง่ของสิ่งที่เราสามารถทำได้ในเชิงพื้นฐานเพื่อเปลี่ยน compute ecosystem เรามีธุรกิจ 3 ส่วน: data center/cloud, edge และ physical AI และแน่นอนว่าแต่ละส่วนเป็นธุรกิจที่ต่างกันมาก แต่ถ้ามองตำแหน่งของ Arm ว่าเรามาจากไหน — จากมือถือ — แล้วตอนนี้กำลังมุ่งไปไหนในมุมของคลาวด์ และตลาดเกิดใหม่อย่าง physical ผมว่าโดยพื้นฐานแล้ว เรากำลังเปลี่ยนวิธีที่คนมอง Arm ในมุมของ compute ecosystem ดังนั้นผมคิดว่ามันคือเศรษฐศาสตร์ของวิธีที่คุณเคยมอง Arm ในอดีต เทียบกับทิศทางที่เรากำลังไปในอนาคต แน่นอนว่าเราประกาศผลิตภัณฑ์แรกไปแล้ว คือ Arm AGI CPU — และจะมีตามมาอีก อย่างที่มีคนพูดไว้ เราจะไม่พูดถึงผลิตภัณฑ์ที่ยังไม่ประกาศ แต่ผมคิดว่าคุณพอจะเห็นทิศทางการเดินทางของ Arm และ footprint ของเราได้ สรุปสิ่งเดียวคือ ให้มอง Arm ในบริบทของธุรกิจ 3 ส่วนนั้นกับ compute ecosystem และว่ามันจะเปลี่ยนไปอย่างพื้นฐานแค่ไหนเมื่อมี Arm เข้าไปเกี่ยวข้อง นั่นคือวิธีคิดในระดับสูงมาก ๆ

🙋 คำถาม: โอเค ขอทวนกลับนะ — ก็คือ Arm กำลังวิวัฒน์ไปเป็นอะไรบางอย่างที่ต่างจากเดิม?

💬 Arm: ใช่ และผมคิดว่านั่นคือหนึ่งใน — ใช่ ผมคิดว่าเรา — ให้มองเราเป็นแพลตฟอร์มประมวลผลพื้นฐาน (foundational compute platform) สำหรับ AI ซึ่งหมายความว่าตอนนี้เรามี 2 ธุรกิจแล้วชัด ๆ — licensing และธุรกิจชิปที่เพิ่งเกิด และส่วนนั้นจะเปลี่ยนไปอย่างมหาศาลเมื่อเรา scale ต่อไปเรื่อย ๆ — scale ไปกับคลาวด์และอื่น ๆ

05โรดแมปซิลิคอนในอนาคตFuture Silicon Roadmap

Key points
  • data center CPU เป็นตลาดที่มีดีมานด์และไม่ชนกับพาร์ทเนอร์ IP มากนัก
  • โอกาสถัดไปจะเลือกจากพื้นที่ที่ลูกค้าขอและ IP ในบ้านมีบทบาทได้
  • Arm มีพอร์ตโฟลิโอ CPU, GPU ประหยัดพลังงาน และ NPU ขนาดเล็ก
  • มองไปที่ physical AI (ยานยนต์อัตโนมัติ หุ่นยนต์) และอุปกรณ์ personal AI ในบ้าน

🙋 คำถาม: การก้าวเข้าสู่ CPU silicon สมเหตุสมผลมาก — คุณมี IP อยู่แล้ว มี CSS มีลูกค้าอย่าง Meta ที่บอกว่า "เฮ้ เราไม่จำเป็นต้องทำ CPU เองตรงนี้ ทำไมพวกคุณไม่รับไปทำเลยล่ะ?" แล้วถัดจาก CPU silicon ไป ซิลิคอนประเภทอื่นที่อาจออกมาจาก Arm ตามลำดับธรรมชาติคืออะไร? ผมรู้ว่าคุณไม่เปิดเผยผลิตภัณฑ์ใด ๆ แต่เราจะคิดเชิงทิศทางเรื่องก้าวต่อไปได้อย่างไร?

💬 Arm: ผมคิดว่าหนึ่งในวิธีที่เรามอง — ผมคิดว่าคุณก็พูดไว้ได้ตรงแล้ว — คือตลาด data center CPU มีความต้องการจากฝั่งลูกค้า และมีโอกาสที่ไม่ได้ชนกับพาร์ทเนอร์ IP ของเราในพื้นที่นั้นมากนักใช่ไหม ดังนั้นเวลาเราประเมินโอกาสอื่นแบบเดียวกัน เราจะดูพื้นที่ที่มีโอกาสแบบนั้น — มีดีมานด์ และลูกค้ากำลังขอให้เราทำ อีกมุมหนึ่งที่ผมจะคิดคือ อย่างที่บอก เรามี install base มหาศาลจากธุรกิจ IP — ตลาดเหล่านั้นจะวิวัฒน์ไปทางไหนเมื่อ AI workload เข้าไปถึง? ถ้าคิดถึงโลกกายภาพ โลกของ physical AI อย่างระบบขับขี่อัตโนมัติ หุ่นยนต์ — workload เหล่านั้นกำลังไปไหน จะเรียกร้องจากฮาร์ดแวร์มากขึ้นตรงไหน — มีแอปพลิเคชันที่ Arm ทำได้ไหม? โดยอิงจาก IP ที่เรามีในบ้านใช่ไหม เรามีพอร์ตโฟลิโอ CPU มีพอร์ตโฟลิโอ GPU ประหยัดพลังงาน เรามีแม้แต่ NPU ขนาดเล็ก และ ecosystem ของ IP ทั้งหมด ดังนั้นถ้าดูตลาดเหล่านั้น ทั้งฝั่ง physical และฝั่ง edge — แล้วอุปกรณ์ personal AI จะหน้าตาเป็นอย่างไร? มันจะไม่ใช่ rabbit pin ที่เราติดอยู่ใช่ไหม แล้วมันจะเป็นอะไร? มันน่าจะเป็นอะไรสักอย่างในบ้าน แบบนั้น ซึ่งจะต้องใช้ workload ที่มีดีมานด์และเราน่าจะรองรับได้ เราจึงมองจากมุมนั้น — ตรงไหนมีโอกาส ตรงไหนมีดีมานด์จากลูกค้า และตรงไหนที่ IP ของเรามีบทบาทได้

Section summary

ก้าวต่อไปของซิลิคอน Arm จะตามดีมานด์ลูกค้าและ install base ของ IP

  • อุปกรณ์ personal AI "จะไม่ใช่ rabbit pin" แต่น่าจะเป็นอะไรสักอย่างในบ้าน

06AGI CPU — กรณีใช้งานและโรดแมปAGI CPU — Use Cases & Roadmap

Key points
  • กรณีที่ 1: general purpose — แทนที่ x86 และฐานข้อมูลอเนกประสงค์
  • กรณีที่ 2: head node ของ accelerator — Cobalt 200 GA กับ Microsoft และ head node กับ TPU variants
  • กรณีที่ 3: agentic racks ที่รัน agent พร้อมกันจำนวนมาก
  • โรดแมปเน้น concurrent threads, ประสิทธิภาพพลังงาน และ confidential compute

🙋 คำถาม: สำหรับ data center CPU — AGI CPU เป็นจุดเริ่มต้นที่ดีใช่ไหม แต่ในพื้นที่นี้ แม้แต่การใช้งานใน data center ก็ชัดว่าชิปแบบเดียวรองรับทุก workload ไม่ได้ จะมี CPU หลากหลายแบบทยอยออกมา แล้ว AGI วางตำแหน่งตัวเองในพื้นที่นี้อย่างไรตอนนี้ และคุณเห็นมันไปทางไหนในอนาคต? จะไปทาง low power — แอปพลิเคชันที่ TCO ดีกว่า หรือไปทาง high core count เทียบเท่า AMD Venice หรือจะโฟกัสที่ confidentiality — พื้นที่ CPU แบบเข้ารหัส? เพราะ TPU — Google TPU — ใช้ชิปของ AMD เฉพาะฝั่งการเข้ารหัส แล้วในเชิงทิศทางคุณเห็นมันไปทางไหน?

💬 Arm: ถ้าคิดถึง Arm AGI CPU ผมว่ามี 3 กรณีใช้งานจริง ๆ ที่มันลงตัว หนึ่งคือ general purpose — แทนที่ x86 และฐานข้อมูลอเนกประสงค์ต่าง ๆ อย่างที่สองคือเป็น head node ให้ accelerator จำนวนมาก คุณจะเห็นทั้ง custom ASIC ที่ใช้ Arm — เราประกาศ Cobalt ไปเมื่อวานกับทีม Microsoft คือ Cobalt 200 GA และอื่น ๆ — และเราประกาศ head node ของเรากับ TPU variants เมื่อสัปดาห์ก่อน ทั้งหมดนี้เป็นตัวอย่างที่ดีว่าคุณจะเห็นได้ทั้ง custom ASIC ที่ใช้ Arm หรือ Arm AGI CPU ที่ทำหน้าที่เป็น head node และอย่างที่สามคือ agentic racks ที่รัน agent พร้อมกันจำนวนมาก เวลามองระบบ agentic ระดับ rack สิ่งที่ต้องคิดคือสเกลระดับ rack และเมื่อคิดถึงสเกลระดับ rack มันคือทั้งประสิทธิภาพพลังงานและจำนวน thread ที่รันพร้อมกันได้มากขึ้น สำหรับเรา เวลาคิดถึงโรดแมป CPU เจเนอเรชันถัดไป เราไม่ได้คิดแค่เรื่อง concurrent threads — การรัน agent ได้มาก ๆ หรือให้ได้มากที่สุดใน rack เดียวด้วย power footprint ที่ลดลง — แต่เรายังคิดด้วยว่า อย่างที่ทุกคนรู้ ดูสิ่งที่เกิดขึ้นทุกวันเรื่องความปลอดภัย — confidential compute จะเป็นข้อกำหนดที่สำคัญขึ้นเรื่อย ๆ รวมถึงความสามารถด้านความปลอดภัยที่ดีโดยทั่วไป ดังนั้นคุณนึกภาพได้เลยว่าโรดแมปในอนาคตของเราจะรวมความสามารถเหล่านั้นหลาย ๆ แบบ และอีกมาก นั่นคือวิธีคิดเรื่องนี้ เรากำลังตอบโจทย์ทั้ง 3 ตลาด มันจะไม่ใช่การเลือกอย่างใดอย่างหนึ่ง — เรามองว่ามันจะได้รับการเสริมให้ยอดเยี่ยมจริง ๆ ในทั้ง 3 กรณีใช้งาน

💬 Arm: SoftBank เป็นลูกค้าของ Arm ที่เราเปิดเผยว่ามีรายได้สูงมาก ผมคิดว่าคุณอาจเห็นในผลประกอบการล่าสุดว่ามันค่อนข้างทรงตัวแล้ว ผมจะบอกว่าไม่มี — เราไม่ได้พึ่งพา SoftBank ในฐานะลูกค้าอย่างมาก เขาเป็นลูกค้า เราทำงานกับเขาในบางโปรเจกต์ แต่เขาไม่ใช่ — เราไม่ได้มีลูกค้ารายเดียว และไม่ได้คิดเป็นสัดส่วนที่ใหญ่ ผมคิดว่าเราผูกพันกับ SoftBank อย่างใกล้ชิดในหลายแง่ Rene มีตำแหน่งทางการที่ SoftBank Group International SoftBank กำลังลงทุนทั่วทั้งกระดานใน data center ด้านพลังงาน และร่วมมือข้าม ecosystem ดังนั้นความสัมพันธ์จึงใกล้ชิด ผมขอยกเรื่องการหาเงินทุนของ SoftBank ให้เป็นเรื่องของ SoftBank เขาเป็นลูกค้าที่ยอดเยี่ยมและพาร์ทเนอร์ที่ยอดเยี่ยมของเรา แต่ผมจะบอกว่าเราไม่ได้พึ่งพาเขาอย่างมาก

🙋 คำถาม: โอเค ขอถามต่อ เพื่อให้บริบท — ผมเขียนเรื่องญี่ปุ่นเป็นหลัก เลยอยากถามนิดหน่อยเกี่ยวกับชุดโอกาสที่คุณเห็นในญี่ปุ่น โดยเฉพาะกับการพัฒนาอย่างรวดเร็ว ซึ่งแน่นอนว่าล่าช้าไป อีกครั้ง SoftBank ก็มีส่วนเกี่ยวข้องที่นั่นด้วย เลยน่าสนใจที่จะเข้าใจว่าคุณมองอะไรเป็นโอกาส? คุณใช้ประโยชน์จากความสัมพันธ์กับ Masa ได้ไหม? คุณเห็นภาพการเติบโตตรงนั้นอย่างไร?

💬 Arm: แน่นอน หนึ่งในจุดแข็งของ Masa คือมีความสัมพันธ์ครอบคลุมทุกวง โดยเฉพาะในแวดวงเทค ญี่ปุ่นมีโอกาสมากมาย รัฐบาลญี่ปุ่นตั้ง coalition เมื่อปีที่แล้วที่ลงทุนในไซต์ SoftBank Portsmouth ผมจึงว่ามีการผสมข้ามสายพันธุ์ (cross-pollination) เกิดขึ้นบ้าง — คนญี่ปุ่นลงทุนในสหรัฐฯ และ SoftBank ก็พยายามนำบางส่วนกลับไปญี่ปุ่น SoftBank มีไซต์บางแห่งในญี่ปุ่นที่กำลังก่อสร้างอยู่ ผมคิดว่ามี Shark Factory (ถอดเสียงมาแบบนี้ — น่าจะหมายถึงโรงงานของ Sharp) ที่ประกาศว่าเขาซื้อมาแล้วกำลังดำเนินการอยู่ และเรายังร่วมมือกับ SoftBank KK ซึ่งเป็นบริษัทโทรคมนาคมที่นั่น ผมคิดว่าเขาเป็นหนึ่งในผู้ให้บริการโทรคมนาคม 3 อันดับแรกของที่นั่น ถ้าผมจำไม่ผิด พวกเขามีปฏิบัติการทั้งหมดที่นั่นซึ่งเรามีโอกาสได้ทำงานด้วยใช่ไหม เขามี data center ที่รันอยู่สำหรับธุรกิจโทรคมนาคม และกำลังดูว่าจะทำอะไรกับมันได้บ้าง ดังนั้นจึงมีโอกาสมากมายที่เราจะร่วมมือกันที่นั่น

ประเด็นสำคัญKey takeaways
  1. 🖥 ดีมานด์ CPU rack แบบ standalone พุ่งทะลุเพดาน — agent ที่รันเป็นชั่วโมงต้องการ CPU core เฉพาะตัว data center จึงเติม CPU rack ล้วน ๆ เพิ่มนอกเหนือจาก head node ใน GPU rack นี่คือสัญญาณที่ตรงที่สุดในเซสชันนี้ว่า agentic AI ขยายตลาด CPU จริง
  2. 📈 TAM ของ data center CPU ขยับต่อเนื่อง — จาก $60 พันล้านดอลลาร์ (ก่อนงาน ARM Everywhere เดือนมีนาคม) เป็น $100 พันล้านดอลลาร์ เมื่อเปิดตัว AGI CPU ขณะที่ซีอีโอรายอื่นพูดถึง $220-$240 พันล้านดอลลาร์ และ Arm บอกว่าตัวเลขนี้ยัง "ต่ำกว่า" ที่เขาเชื่อ
  3. 🔄 Arm ไม่ใช่แค่ธุรกิจ licensing อีกต่อไป — สารหลักที่ผู้บริหารอยากให้ตลาดเข้าใจคือ Arm มี 2 ธุรกิจ (licensing + ชิป) ภายใต้ 3 ตลาด (data center/cloud, edge, physical AI) และธุรกิจชิปจะเปลี่ยนภาพไปมากเมื่อ scale
  4. 🧠 AGI CPU เล็ง 3 กรณีใช้งานพร้อมกัน — general purpose แทน x86, head node ของ accelerator (Cobalt 200 GA กับ Microsoft, head node กับ TPU variants) และ agentic racks — โรดแมปข้างหน้าเน้น concurrent threads, power efficiency และ confidential compute
  5. ⛓ ซัพพลายตึงทั้งห่วงโซ่จนถึงปี 28 — คอขวดไม่ได้อยู่แค่เวเฟอร์/หน่วยความจำแต่ลามถึงซับสเตรตและวัสดุซับสเตรต กำลังการผลิตใหม่เข้ามาช่วงปลายปี 27-28 Arm เพิ่มซัพพลาย CPU ปีหน้าแล้วแต่ยังขายได้มากกว่านี้ถ้ามีของ
  6. 🔁 Meta พิสูจน์ว่าการพอร์ตจาก x86 ไม่ยากอย่างที่คิด — ทำให้ลูกค้ารายอื่นคำนวณว่าต้นทุนพอร์ตเป็นแค่ส่วนหนึ่งของ TCO benefit ส่วน legacy long tail อาจไม่ย้าย แต่ workload ใหม่แบบ agentic เป็นพื้นที่ว่างที่ Arm ได้เปรียบเรื่อง TCO
  7. 🏦 SoftBank: ใกล้ชิดแต่ไม่พึ่งพา — รายได้จาก SoftBank "ทรงตัว" แล้ว Arm ย้ำว่าไม่ได้พึ่งพาเป็นสัดส่วนใหญ่ และเลี่ยงตอบเรื่องการนำหุ้น Arm ไปวางเป็นหลักประกัน โดยบอกว่าเป็นเรื่องของ SoftBank
  8. 🇯🇵 ญี่ปุ่นเป็นโอกาสผ่านเครือข่าย Masa — ไซต์ SoftBank ในญี่ปุ่น โรงงานที่ซื้อมา และความร่วมมือกับ SoftBank KK (ผู้ให้บริการโทรคมนาคม 3 อันดับแรก) ที่มี data center อยู่แล้ว ส่วนเรื่อง custom CPU กับ OpenAI ผู้บริหารปฏิเสธที่จะให้ความเห็น
